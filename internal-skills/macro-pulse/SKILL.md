# 宏观风向

**做的是环境刻画，不是买卖信号。** 输出「现在处在什么样的宏观环境里」，
不出现"建议买入/减仓/加仓"这类话。

## 第一步：取数

```bash
~/.kalo/market/venv/Scripts/python.exe ~/.kalo/skills/market-data/md.py macro analyze
```

输出是紧凑表格 JSON：

```json
{"as_of":"2026-08-20","samples":250,"window":250,
 "cols":["key","v","pct","d1","d5","d20","d60"],
 "rows":[["dxy",98.72,50.8,-1.4,0.29,-0.88,-0.72], ...],
 "pp_keys":["us10y","us2y",...],
 "divergences":[["BTC-纳指","diverging"]]}
```

- `v` 现值，`pct` 在历史窗口中的百分位（100 = 区间最高），`d1/d5/d20/d60` 是 1/5/20/60 交易日变化。
- **`pp_keys` 里的指标，`d*` 的单位是「个百分点」，其余是「百分比」。** 收益率从 4.60
  到 4.65 是「上行 5 个基点」，不是「上涨 0.05%」，写报告时别搞错。
- 有 `warning` 字段就照抄进结论：样本不足时分位数不可靠，只能看方向。

数据太旧（`as_of` 不是最近一个交易日）时，先跑一次 `md.py macro append` 补上再分析。

## 指标对照表

| key | 指标 | 读法 |
| --- | --- | --- |
| `dxy` | 美元指数 | 全球流动性总闸，↑ 压制新兴市场与商品 |
| `us10y` / `us2y` | 美债 10Y / 2Y | 全球资产定价锚 |
| `term_spread_us` | 美债 10Y-2Y 期限利差 | < 0 是倒挂，经典衰退信号 |
| `cn10y` | 中债 10Y | 国内利率与增长预期 |
| `cn_us_spread_10y` | 中美 10Y 利差 | 越负，人民币压力与外资流出压力越大 |
| `usdcny` | 美元兑人民币 | ↑ 即人民币贬值 |
| `gold` / `copper` / `oil` | 纽约金 / 铜 / 油 | 避险 / 经济动能 / 通胀 |
| `copper_gold_ratio` | 铜金比 | 经济动能 vs 避险的经典比值，↓ 即避险占优 |
| `vix` | VIX | 恐慌指数，> 20 情绪紧张，> 30 恐慌 |
| `btc` | 比特币 | 高频风险偏好代理，常领先股市 |
| `nasdaq` / `hsi` | 纳指 / 恒生 | 外部风险资产 |
| `sh_index` / `cyb_index` | 上证 / 创业板指 | 创业板相对上证强弱 = 风险偏好内部结构 |
| `total_turnover_yi` | 两市成交额（亿元） | **A股最重要的单一指标**，量能决定题材能否扩散 |
| `limit_up_count` / `broken_board_count` | 涨停 / 炸板家数 | 炸板/涨停比高 = 情绪退潮 |
| `margin_balance` | 两融余额（沪市） | 杠杆资金进出，慢变量 |

## 判断规则

统一形态：**先看分位数（相对位置）→ 再看方向（d5 / d20）→ 最后组合**。
单个数字不构成判断，组合才构成。

**流动性与利率**
- `dxy` ↑ 且 `us10y` ↑ 同步 → 美元流动性收紧，压制新兴市场、黄金与成长股
- `dxy` ↓ 且 `us10y` ↓ → 宽松交易，利好风险资产与人民币资产
- `term_spread_us` < 0 → 倒挂中；从倒挂转正（`d20` 明显为正）历史上常伴随衰退临近而非解除
- `cn_us_spread_10y` 走阔（更负） → 人民币贬值压力↑，外资流入受抑

**风险偏好**
- `copper_gold_ratio` ↓ 且 `vix` ↑ → 避险模式开启
- `vix` 分位 > 80 → 情绪已在极端区，反身性风险（既可能继续恐慌，也容易反弹）
- `divergences` 里 BTC-纳指 `diverging` → 全球风险偏好边际转向，BTC 通常领先

**A股自身**
- `total_turnover_yi` 分位 < 30% 且 `limit_up_count` 低位 → 存量博弈，题材难扩散
- `total_turnover_yi` 放大（`d5` > 20%）但指数不涨 → 分歧加大，警惕高位换手
- `broken_board_count` / `limit_up_count` > 0.4 → 情绪退潮，接力风险高
- `cyb_index` 的 `d20` 显著强于 `sh_index` → 风险偏好回升，资金愿意买贵的

**跨市场**
- 外部（纳指/恒生）强而 A股量能萎缩 → 内部因素主导，别把外盘涨当成 A股理由

## 输出格式

1. **一句环境刻画**：例如"偏紧的美元环境 + 低迷的本土量能"。
2. **分位数表**：只列有信息量的指标（分位数极端、或近期变化显著的），
   每行「指标 · 现值 · 分位 · 5日/20日变化」，不要把 20 条全倒出来。
3. **3–5 条组合判断**：每条形如「A 与 B 同时出现 → 意味着 C」，
   必须点名依据的指标与数值。
4. **一句「什么会让这个判断失效」**：写出最需要盯的那个变量。

**约束**
- 每个判断都要落到具体数值，不要"美元走强"这种没有数字的话。
- `warning` 存在时（历史 < 60 个交易日），在开头明说"分位数样本不足，仅作方向参考"。
- 数据缺失就说缺失，不要用其他指标脑补填空。
- 不给买卖建议、不给点位预测、不给仓位比例。
