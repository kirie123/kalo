# 个股体检

**做的是体检报告，不是荐股。** 逐项说清「这项指标现在是什么数、按判据算健康还是
不健康」，**不出现"建议买入/持有/减仓/目标价"这类话**。用户自己做决定。

## 第一步：取数

```bash
~/.kalo/market/venv/Scripts/python.exe ~/.kalo/skills/market-data/md.py stock checkup <6位代码>
```

一条命令拿全三大类的事实（约 7 KB JSON），**不要自己去 web_fetch 行情**——
那样字段是猜的、没有前复权、也没有历史可比。

顶层结构：

```
code / name / as_of / last_bar / bars     基本信息；last_bar 是最后一根日线的日期
quote                                     实时快照：price / chg_pct / turnover_rate / pe / pb / 市值
risk      → pledge, lift_upcoming, block_trades_recent, holder_changes_1y, announcements_recent
health    → volume, pressure, ma, macd, rsi, bias, shapes_20d, stagnation_10d
catalyst  → boards, fund_flow_20d, limit_ups_20d
errors[]                                  哪条源没取到（缺了就说缺了，别当成 0）
```

**盘中运行时 `last_bar` 就是今天，最后一根 K 线是未收盘的临时值**，据此算的
MA/MACD/RSI 会随尾盘变动——报告里要提一句。

补充取数（需要时才跑，各自单独一条命令）：

```bash
md.py filing metrics <code>          # 近 12 期 EPS/ROE/营收/净利/毛利率/现金流
md.py filing list <code>             # 定期报告清单（查审计意见要先下年报）
```

## 第二步：逐项判断

判据写在下面。**它们是判据不是真理**——数值贴近边界时说"接近"，别硬套。
每一项都要给出「数值 + 结论」，只给结论等于让人没法核对。

### （1）风险排查

| 项 | 看哪个字段 | 判据 |
| --- | --- | --- |
| 财报基本面 | `md.py filing metrics` | 营收/净利同比连续两期为负、毛利率持续下滑、经营现金流与净利长期背离 → 记为风险 |
| 高比例质押 | `risk.pledge.ratio_pct` | >30% 高，>50% 危险；<5% 基本无虞。0 或极小值说明没有质押 |
| 审计意见 | 年报 PDF | 非"标准无保留意见"即为风险。**未下载年报就直说没查，不要猜** |
| 函件与立案 | `risk.announcements_recent` 标题 | 出现「问询函」「关注函」「警示函」「立案」「处罚」「监管措施」→ 逐条列出标题与日期 |
| 解禁 | `risk.lift_upcoming` | 只含**未来**的批次。`ratio_of_float` >10% 是明显压力，>30% 是重大压力；空数组 = 无待解禁 |
| 减持公告 | `risk.holder_changes_1y` | `direction` 为「减持」且在近 20 天内 → 风险项；一年内多次减持要说明频率 |
| 大宗折价 | `risk.block_trades_recent` + `block_discount_count` | `premium_ratio` 为负即折价。折价 >5% 且笔数多 → 有资金在低价出货 |

公告标题里除了风险词，也要顺手挑出**利好类**（中标、增资、收购、业绩预增）供第（3）类用。

### （2）健康度度量

**量价（近 20 日）** — `health.volume` / `chg_20d_pct` / `chg_5d_pct` / `turnover_rate`
- `ratio_5_20` >1.3 明显放量，<0.7 明显缩量，0.9~1.1 平稳
- `pct_rank_20d` 是当日成交量在近 20 日中的百分位
- 健康的形态是**价涨量增 / 价跌量缩**；价涨量缩（背离）与价跌量增（恐慌）都要点出来

**压力位** — `health.pressure`
- `drop_pct` 从近百日最高点跌了多少，`rebound_pct` 从最低点弹了多少
- `recovery_pct` 是现价在「低点→高点」区间的位置（0=还在低点，100=已回前高）
- **>70% 时套牢盘接近解套，抛压变大**，这正是清单担心的"解套跑路出货"；50%~70% 中性；<30% 说明反弹刚起步
- `shape`：`down_then_up` 跌完在反弹 / `down` 还在下跌途中 / `up` 高点就是最新一根

**均线** — `health.ma`
- `bull_aligned` = MA5>MA10>MA20>MA60（多头排列），`all_rising` = 四条 `slope3` 都为正
- 清单要的是**两者同时成立**：排列对且没有一条拐头向下
- `slope3` 是"当前值 - 3 日前值"，负数即拐头向下，要指名是哪一条
- `bull_aligned` 为 `null` = 日线不足 60 根，判不了，如实说

**MACD** — `health.macd`
- 清单三问：`dif_above_zero`（DIF 在 0 轴上）、`dif_falling_3d`（DIF 有无拐头向下）、
  `hist` > 0 即红柱、`hist_growing_3d`（红柱近 3 天持续变长）
- `hist_seq_4d` 是最近 4 天的柱值，可直接引用来说明变化过程
- 四条全部满足才算"MACD 健康"；缺哪条说哪条

**RSI / BIAS** — `health.rsi` / `health.bias`
- RSI6 >80 超买（>90 极端），<20 超卖；RSI12/24 >70 说明中期也在高位
- **三条 RSI 同时高位 = 加速冲顶，是清单最担心的形态**
- BIAS6 >6%、BIAS12 >10%、BIAS24 >15% 属偏离过大（题材股容忍度更高，要结合它自己的历史看）
- 负值同理表示超卖与向下偏离

**形态** — `health.stagnation_10d` / `health.shapes_20d`
- 滞涨的判据是**涨幅小而振幅大**：`range_pct` 接近 0（如 |x|<3%）但 `amplitude_pct` 明显（如 >8%），且 `new_high_count` 很少 → 震荡滞涨
- `close_in_range` 是收盘价在近 10 日区间中的位置，低位说明每次冲高都被打下来
- `shapes_20d.counts`：长上影 / 十字星 / 墓碑线的出现次数，**近 20 日累计 ≥3 次视为频繁**，是冲顶乏力的信号
- `bars_ago` 是最近一次出现在几根之前（0 = 就是最后一根），越近越值得注意

### （3）催化契机

- `catalyst.boards`：关联概念板块（`rank` 是该股在板块内的排名，越小越核心）。
  **要判断"这些板块最近有没有重大消息催化"必须联网查**——脚本只给标签，
  不给板块新闻。用 web_search 查排名靠前的 2~3 个板块的近期消息，查不到就说没查到。
- `catalyst.fund_flow_20d`：`main_net_sum_yi` 近 20 日主力净流入合计（亿元），
  `inflow_days` 净流入天数。**持续净流入的判据是合计为正且 `inflow_days` ≥ 12**；
  合计为负但天数过半 → 流出集中在少数几天，属于大额出货，要点出来
- `catalyst.limit_ups_20d`：近 20 日涨停。健康的涨停是**放量**（`vol_ratio_ma5` >1.5）
  且**次日不大跌**（`next_day_chg_pct` 不显著为负）；缩量涨停或次日回落说明封板不实
- 个股自身催化看 `risk.announcements_recent` 里的利好类标题

## 第三步：输出

按三大类分节，每节先列逐项事实与判断，末尾一句小结。整体结构：

```
## 贵州茅台 600519 · 数据截至 2026-08-20 18:30（盘中，最后一根未收盘）

### 一、风险排查
- 质押：0.04%，无虞
- 解禁：未来无待解禁批次
- 大宗：近 20 日 11 笔，其中 1 笔折价 9.06%（07-31，429.9 万元）
- 公告：近 20 条无问询函/立案类
- 审计意见：未下载年报，本次未核查
→ 小结：一句话

### 二、健康度
（量价 / 压力位 / 均线 / MACD / RSI-BIAS / 形态，每项「数值 → 结论」）
→ 小结：一句话

### 三、催化
（概念板块 / 资金流 / 涨停）
→ 小结：一句话

### 未取到的数据
（errors[] 里的源，没有就省掉这节）
```

收尾固定一句：**这是事实体检，不构成投资建议。**

## 纪律

- **数字全部来自脚本输出，一个都不要口算。**指标算错比不算更糟。
- `errors[]` 里的源要单列出来说"这项没查到"，**绝不用其他数据脑补**。
- `bars` < 60（次新股）时 MA60、百日回撤都不可用，输出里会带 `warning`，照抄。
- 判据边界值不要装作确定：`recovery_pct` 68 就说"接近解套区"，不是"未达阈值，安全"。
- 用户只问某一类（"它技术面怎么样"）时**只答那一类**，不要三类全铺。
