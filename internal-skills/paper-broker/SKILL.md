# paper-broker 纸交易账本

**这是纸交易记录工具，不构成投资建议，不发生任何真实交易。**

## 铁律（agent 必须遵守）

- **账户状态（现金、持仓、收益）只能通过 `broker.py` 命令变更。** 禁止用写文件、
  改 JSON、跑 SQL 等任何方式直接改 `ledger.jsonl` / `state.json`。
- 账本是 append-only 哈希链：手改会被 `verify` 立刻查出并告警。
- 成交价默认取 market-data 前复权日线的当日收盘价；决策时要按决策价成交，
  用 `--price` 显式传入并在决策记录里说明价格来源。
- 取不到价格时 CLI 会报错退出——**不要自己编一个价格**。

## 运行方式

```bash
PY=~/.kalo/market/py
BROKER=~/.kalo/skills/paper-broker/broker.py
$PY $BROKER positions <账本目录>
```

账本目录由使用方定（投资类数字专家一般放在 `<专家工作目录>/broker/`）。

## 命令

| 命令 | 用途 |
| --- | --- |
| `init <dir> --cash 1000000` | 初始化账本（一个目录只能 init 一次） |
| `deposit <dir> <金额>` / `withdraw <dir> <金额>` | 出入金 |
| `buy <dir> <代码> <股数> [--price P] [--date D] [--name 名称]` | 买入。股数必须 100 的整数倍 |
| `sell <dir> <代码> <股数> [--price P] [--date D]` | 卖出。T+1：当日买入当日不可卖；可卖零股 |
| `settle <dir> [--date D]` | 收盘结算：按当日收盘价重估，快照入链 |
| `positions <dir>` | 当前现金与持仓（含 T+1 可用数量） |
| `pnl <dir>` | 净入金 / 最新市值 / 总收益 / 最大回撤 / 已实现收益 |
| `history <dir>` | 全部账本流水 |
| `verify <dir>` | 重放校验哈希链与派生状态；不一致非零退出 |

## 规则（代码内置，不凭记忆）

- 佣金：万 2.5、最低 5 元，买卖双向；印花税：千 1，仅卖出。
- 买入校验现金（含佣金），卖出校验 T+1 可用持仓。
- A 股 6 位代码；定价走 market-data 的 `stock_kline` 源（前复权，带缓存，
  只覆盖近约 130 个交易日——更早的日期必须 `--price` 显式给价）。

## 收尾固定声明

任何向用户展示账本结果的场合，末尾固定一句：**这是纸交易记录，不构成投资建议。**
