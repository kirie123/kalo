# 财报下载与分析

**只做事实归纳与异常标注，不给估值结论、不给买卖建议。**

## 取数

```bash
PY=~/.kalo/market/py
MD=~/.kalo/skills/market-data/md.py

$PY $MD filing metrics 600519 --periods 12    # 结构化财务指标，先看这个
$PY $MD filing list 600519 --type 年报         # 有哪些期，多大
$PY $MD filing get 600519 --year 2025 --type 年报   # 下 PDF + 抽文本
```

`--type` 取 `年报` / `半年报` / `一季报` / `三季报`；`get` 不给 `--year` 就取最新一期。
文件落在 `~/.kalo/filings/<代码>/`，重复调用直接复用已下好的，不会重下。

## 顺序：先表后文

**永远先跑 `filing metrics`。** 它给的是近 N 期的结构化对照表（每股收益、营收、
归母净利、同比、毛利率、净利率、ROE、资产负债率、经营现金流/营收、应收与存货
周转天数），几 KB 就能看清多期趋势。

**PDF 正文只在有具体问题时才读**——年报 200+ 页、抽出来十几万字，整本进上下文
既不可能也没必要。正确用法是先从表里发现异常，再去正文找解释：

```bash
rg -n "存货" ~/.kalo/filings/600519/600519-2025-年报.txt | head -20
```

抽出的 txt 带 `--- p.N ---` 页码标记，引用时说清在第几页。

## 分析框架

1. **趋势**：营收 / 净利 / 扣非净利的多期走向。同比是加速还是减速？扣非与归母
   差多少（差距大 = 利润里非经常性损益占比高）？
2. **质量**：毛利率、净利率、ROE 的方向。毛利率下滑而营收增长 = 以价换量。
3. **现金流背离**（最重要的一条线索）：净利润增长但 `经营现金流/营收` 下滑，
   说明利润没变成钱，通常对应放宽信用或压货。
4. **应收与存货**：周转天数拉长 = 回款变慢 / 卖不动。这两个是最早的预警信号。
5. **杠杆**：资产负债率的变化方向，配合行业常态看。
6. **从正文找解释**：把 1–5 里发现的异常拿去正文检索（管理层讨论与分析、
   会计政策变更、关联交易、重大合同），看公司自己怎么说。
7. **审计意见**：正文搜「审计报告」，确认是标准无保留意见；带强调事项段、
   保留意见、无法表示意见的，**这是第一位的信息，要写在最前面**。

## 输出格式

1. **一句话总结**：这几期财报讲了什么故事。
2. **关键指标表**：3–5 期对照，只列有变化的行。
3. **2–4 条异常标注**：每条写「现象（带数字）→ 可能原因 → 正文里的说法/正文没提」。
4. **数据缺口**：哪些想看的没拿到（比如分产品拆分只在正文里、或某期数据源缺失）。

**约束**
- 每条结论必须落到具体数字与报告期，不写"业绩不错"这种话。
- 区分「财报事实」与「我的推测」，后者要显式标注。
- 审计意见非标准时，必须在开头点明。
- 不做估值、不给目标价、不给买卖建议。
