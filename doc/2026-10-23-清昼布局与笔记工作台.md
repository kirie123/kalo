# 清昼布局、可切换皮肤与图文笔记

## 已选方向

统一采用清昼布局：顶部标题横条、常驻竖向工具栏、页面自己的侧栏、主内容区。纸间与深航只作为皮肤切换，导航位置、列宽、圆角、操作顺序不变。纸间使用纸张底色与鼠尾草绿，正文标题有书写感；深航使用墨蓝底色与薄荷绿。默认清昼，保留明暗模式与跟随系统设置。

## 桌面外壳

- 标题栏高 48px，左侧品牌及应用菜单、中间当前页面、右侧行情入口和窗口控制。拖动区域避开所有按钮，继续使用 Tauri 窗口 API。
- 竖向工具栏宽 58px，固定提供对话、笔记、自动化、专家、演化入口，设置固定在底部。所有页面都显示当前选中状态和辅助名称。
- 主面板左上角圆角 18px、细分隔线。会话侧栏只在对话页显示；笔记与设置使用自己的分类侧栏，避免出现两层不相关的导航。
- 设置页增加搜索、图标和分组，正文保持适合阅读的最大宽度；外观页提供清昼、纸间、深航与明暗选择。
- 皮肤以 `kalo.skin` 保存为 `clear | paper | night`；旧 `kalo.theme` 原样保留。深航固定使用深色令牌，明暗偏好保存后在切换回其他皮肤时继续生效。
- OS 差异仍由既有窄适配层处理；本改动不改变 sidecar、资源定位、进程和打包契约。Windows 与 macOS 使用同一套前端布局和快捷键判断（Ctrl / Cmd）。
- 现有可视化卡片同时监听明暗 class 与 `data-skin` 变化；皮肤配色在已打开的卡片里实时同步。

## 图文笔记

继续使用 `~/.kalo/knowledge/` 下的 Markdown 和既有知识库 IPC，不新增引擎协议。

- 左侧为分类与标签，中间为可搜索的笔记摘要，右侧为编辑器；窄窗口自动收起分类树，避免挤压正文。
- 新建笔记直接进入编辑，无需阻塞式标题输入弹窗。标题与正文分开编辑，frontmatter 在日常编辑中隐藏，源码模式保留完整文本。
- 编辑、预览、源码三种视图共用同一份 Markdown。编辑视图将独占一行的图片标记显示成图片块，其余正文保留为可编辑文本；复杂 Markdown 可使用源码与预览。
- 支持选择、粘贴、拖入 PNG/JPEG/GIF/WebP 图片。通过既有 `save_attachment_bytes` 将副本存入 `~/.kalo/attachments/`，Markdown 保存绝对路径，原图片移动后笔记仍有效。图片最多 10 MiB，失败显示错误，不插入无效引用。导出或搬迁笔记时需要一并复制附件。
- 桌面端使用 Tauri webview 的原生文件拖入事件，并按缩放后的坐标判断是否落在编辑器；浏览器预览使用 DOM drop。拖入文件先读取限额内的图片字节再复制，两个平台都不把原文件路径直接当成持久附件。
- 本地图片使用既有图片读取和放大组件；旧笔记的相对图片路径以该笔记所在目录解析。Windows 盘符、UNC、macOS POSIX 路径在纯逻辑层统一解析。
- 停止输入约 1 秒后自动保存；保存队列串行写入，切换笔记、新建、删除前等待当前写入完成，失败时留在当前笔记并提供重试。
- 每次编辑同步保留浏览器本地草稿。保存成功仅删除与本次保存内容完全相同的草稿；正在输入的更新草稿不得被较早的保存结果删除。重新打开笔记时恢复未保存草稿并提示。离开笔记页的卸载清理会提交最后快照，草稿用于异常退出恢复。
- 笔记读取与搜索均用请求序号丢弃过期响应。读取期间禁止编辑，失败不将前一篇正文写入新路径。删除前等待保存队列排空，删除后清理草稿。
- 文件覆盖与删除继续走后端 `.trash/` 备份行为。自动保存不修改已有 frontmatter 的扩展属性；新笔记只带标题、日期、域与状态。

## 分层与验证

皮肤解析、frontmatter 更新、图片块识别、路径解析、保存排队放在纯逻辑模块；文件读取、附件写入与草稿持久化放在 feature 适配层；组件负责展示与事件。为会影响已有内容的解析、路径和保存顺序增加纯逻辑单测；Tauri IPC 与 TSX 不做模拟单测。

运行 changed-aware 检查、前端构建，并用浏览器检查外壳、三套皮肤和笔记布局。真实桌面端的窗口拖动、粘贴图片、重启恢复、文件覆盖备份需要在 Tauri 环境验收，浏览器预览不等于这些行为已验证。
