# 用户气泡长文本折叠（展开 / 收起）

## 问题

对话区里用户输入的气泡是原样全量渲染的（`UserBubble` 用 `whitespace-pre-wrap` 直接铺文本）。
贴一段长提示词、一段报错日志、一篇文档正文进去，气泡就变成一堵墙：

- 一条输入占满好几屏，助手的回答被挤到视口外，滚动定位成本高；
- 用户其实只需要"认出这条输入是什么"，不需要每次都完整重读；
- 现有的对折叠支持只在 diff（`DiffView` 的 `collapsible`）里，聊天气泡没有。

## 方案

给用户气泡的文本部分加默认最大高度，超出时裁掉下半部分，并在**气泡矩形内部的右下角**提供
"展开 / 收起"。

### 折叠规则

- 折叠高度上限 `COLLAPSED_MAX_H = 260px`（约 12 行正文）。
- 只有实际内容高度超过上限 + 8px 容差时才算"溢出"，才显示展开按钮；短文本行为完全不变（不加
  按钮、不加渐变、不加额外边距）。
- 高度用 `ResizeObserver` 测量：字体缩放（`chat-zoom`）、窗口宽度变化、附件 chip 换行都会
  改变换行结果，一次性测量会失真。
- 展开状态是气泡本地 UI 状态（`useState`），不入 store、不持久化：会话重载后回到折叠态。

### 按钮位置

要求是"整个气泡矩形的右下角"，不是气泡外面那一行（复制按钮所在的位置）：

- 气泡容器 `relative overflow-hidden rounded-2xl`，按钮 `absolute bottom-1.5 right-2`。
- 折叠态：气泡底部叠一层 `pointer-events-none` 的渐变遮罩（`transparent → var(--bubble)`），
  它是"下面还有内容"的静态提示——不悬浮也能看出被裁了。
- 按钮本身默认 `opacity-0`，气泡 hover 时（`group/bubble`）淡入，避免常驻噪点。
- 展开态没有渐变（不该遮住正文尾部），气泡底部留出 `pb-7` 给"收起"按钮，
  防止按钮压在最后一行字上。

### 组件边界

折叠逻辑做成 `UserBubble.tsx` 内的局部组件 `CollapsibleText`：

- 输入只有 `text`，输出只有渲染 + 本地展开态，无 IPC、无 store 依赖；
- 复制按钮仍在气泡**外**（原位置不动），复制的始终是完整文本，与折叠状态无关；
- 附件 / 图片 chip 不参与折叠，它们在气泡上方、本身高度可控。

## 影响面

- 改动文件：`kalo-desktop/src/components/UserBubble.tsx`。
- 纯展示改动，不碰 `pi-bridge` 契约、不碰 `chat-store` 时间线结构，
  按 `kalo-desktop/AGENTS.md` 的测试边界属于 UI-only（高度测量走 DOM，不进 vitest 的纯逻辑层），
  用人工验证：贴长文本 → 默认裁到约 12 行 + 底部渐变 → 悬浮出现"展开" → 展开后悬浮出现"收起"。
