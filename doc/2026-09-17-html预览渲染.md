# HTML 文件预览：沙箱渲染 + 本地资源内联

日期：2026-09-17

## 背景

文件面板里点开 `.html`，看到的是一坨高亮源码。用户的设计文档库（例如本机的
`docs/proposals/*.html`，左侧目录 + 右侧正文的深色排版）大量以 HTML 形式存在，
点开却是源码，等于预览功能缺了一半。

`doc/2026-09-12-对话区svg渲染.md` 立过规矩：**不开放任意 HTML 执行**，当时的备注是
「`.svg` 文件预览的渲染开关另议」。本文把「另议」落定：**文件预览可以渲染 HTML，
但走沙箱 iframe，与对话区那条「不注入、不执行」的通道完全隔离。**

真正的难点不是「用 iframe 渲染」，而是**资源**：这些文档依赖相对路径的外链
（`<link rel="stylesheet" href="../assets/doc.css">`、`<script src="../assets/doc.js">`、
偶发的 `<img src="figs/x.png">`）。webview 里的 iframe 读不到本地文件系统，直接塞进
iframe 只会得到一份无样式的裸 HTML——比源码还糟。

## 目标与非目标

目标：

- `.html/.htm` 文件渲染成页面（渲染优先，右上角一键切源码），文件面板、全屏预览、
  改动文件弹窗三处共用（都走 `FilePreview`）
- 相对路径的本地资源内联：`<link rel=stylesheet>`、`<script src>`、`<img src>`
- 文档自带的脚本**默认不执行**，工具条一键启用（见下）
- 文内相对链接（如 `../features/F09-任务系统.html`）在应用内打开，不再把 iframe 导航到
  一个不存在的 URL
- `.svg` 文件预览一并改成渲染（原来是「另议」，本次复用对话区的 `SvgBlock`）

非目标：

- 不做内嵌的任意 HTML 执行通道：HTML 只在这个沙箱 iframe 里渲染，对话区那条
  `htmlToMarkdown` 降级路径不动
- 不新增 Tauri 命令、不动引擎契约（只用现成的 `read_file_text` / `read_file_bytes`）
- 不内联 CSS 内部的 `url()` / `@import`（现有文档库的约束就是「不用 @import、不用
  web font」，见其 `doc.css` 首行注释；将来需要再说）
- 不内联 `<video>/<audio>/<source>/srcset`：媒体与响应式图集在文档里罕见，且体积口径
  完全不同（见「边界」）
- 不改远端资源的策略：远端图片/样式保留，远端脚本剥掉；外链点击不跳出（见「边界」）

## 方案

### 分层

```
src/lib/file-kind.ts          纯逻辑：扩展名 → kind（新增 "html" / "svg"）
src/lib/html-doc.ts           纯逻辑：路径解析 + 资源/链接收集 + 文档重写（不碰 IPC/DOM）
src/components/HtmlFrame.tsx  展示 + IO：读资源、组文档串、沙箱 iframe、链接桥
src/components/FilePreview.tsx  case "html" / case "svg" 接入
src/components/FilePanel.tsx   把「预览里再开一个文件」的回调传下去
```

`lib` 里全是字符串进 / 字符串出，`node` 环境可测；所有 `invoke` 集中在 `HtmlFrame`
这一层（符合「IPC 隔离到薄适配层」的约定）。

### 沙箱与脚本（`HtmlFrame`）

iframe 两种模式，只有 `sandbox` 与文档内容不同：

| | 默认（脚本关） | 启用脚本 |
|---|---|---|
| `sandbox` | `""`（无 allow-*） | `allow-scripts` |
| 作者 `<script>` | 整段剥掉 | 本地内联 / 远端剥掉 |
| `on*` 属性、`javascript:` | 剥掉 | 保留 |
| `<meta http-equiv=refresh>` | 剥掉 | 保留 |
| 桥接脚本（链接跳转、Esc 转发） | 不注入 | 注入 |

两种模式都**不带 `allow-same-origin`**：文档跑在不透明源里，拿不到父窗口、localStorage、
cookie，也拿不到 Tauri 的 IPC 入口。默认模式的「脚本关」是字面意义上的一个字都不执行，
因此桥接脚本也只在启用后注入（少了它，文内链接退化成 `href="#"` 的惰性链接，不会把
iframe 导航坏）。

模式是每个文件自己的状态（与 markdown 的「源码」开关同级），不做持久化：默认安全，
要目录/交互就点一下。

### 资源内联（`html-doc.ts` + `HtmlFrame`）

两段式，纯逻辑负责「找出要读什么、怎么拼回去」，组件负责「读」：

1. `collectLocalAssets(html, docPath)` → `LocalAsset[]`：扫 `<link rel=stylesheet>`、
   `<script src>`、`<img src>`，只留**本地**引用（相对路径、盘符/`/` 绝对路径、
   `file://`），带上源码区间 `[start, end)`。
2. 组件按 `asset.path` 读：样式/脚本走 `read_file_text`，图片走 `read_file_bytes` → data URL。
3. `applyAssets(html, assets, resolved)` 按区间倒序替换：样式 → `<style media=…>`，
   脚本 → 内联 `<script>`（脚本关时整段删除），图片 → 改写 `src`。

读失败（文件不存在、超限被截断）**保留原标签**并在工具条下方给一行提示——样式表没内联
成功要看得见，不能默默给一份裸 HTML。资源数量上限 32 个，超出的原样留下（防病态文件）。

路径解析 `resolveLocalPath(url, docPath)` 是纯字符串运算，兼容两种分隔符：剥掉
`?query#hash`、处理 `.` / `..`、识别 `C:\x` 与 `/x` 绝对路径、`file://` 前缀，其余
（`http(s):`、`data:`、`//host`、纯 `#fragment`）返回 `null` 表示不是本地资源。

### 链接（`html-doc.ts` + 桥接脚本）

- **本地文件链接**：`<a href="../features/F09.html">` → 解析成绝对路径，改写成
  `href="#" data-kalo-doc="<绝对路径>"`。启用脚本时点一下 → 桥接脚本
  `parent.postMessage` → 父窗口校验 `event.source === frame.contentWindow` 后：
  有 `onOpenPath` 回调（文件面板）就地在预览里打开该文件；没有（改动文件弹窗）则退回
  `openPath` 交给系统程序。脚本关时 `href="#"` 保证点击是无副作用的空操作。
- **远端链接**：加 `target="_blank" rel="noopener noreferrer"`。沙箱不含 `allow-popups`，
  所以点击不会开窗也不会替换掉文档本身（已知取舍，见「边界」）。
- **Esc**：iframe 会吞掉键盘事件，全屏时父窗口收不到 Esc。桥接脚本把 Esc 转发给父窗口
  （`postMessage({kaloKey:"Escape"})`），全屏照样能退出；脚本关时靠工具条上那个带文字的
  「退出全屏」按钮（`doc/2026-08-27-file-preview-render-and-fullscreen.md` 已修）。

### `.svg` 文件

`file-kind.ts` 新增 `"svg"` kind（从 `text` 里分出来），`FilePreview` 直接渲染
`SvgBlock`——它自带「源码/预览」切换、复制、另存为，以及 `sanitizeSvg` 清洗。等于把
对话区那套能力平移到文件预览，不新写渲染代码。默认渲染（用户点开 `.svg` 就是要看图；
要看源码有切换钮）。

## 测试

`src/lib/html-doc.test.ts`（纯逻辑，node 环境）：

- 路径解析：相对/`..`/`.`/盘符/`/` 绝对/`file://`、剥 query+hash、非本地（`http(s)`、
  `data:`、`//host`、`#frag`）返回 null
- 资源收集：三类标签都收到、远端与 data: 的不收、`rel` 非 stylesheet 的 link 不收、
  区间能原样切回源码
- 应用资源：`<style media>` 保留 media、图片改写 data URL、脚本关时整段删除、未解析
  的资源保持原样
- 脚本剥离：`<script>` 内联与外链都删、`on*` 属性（三种引号）删、
  `javascript:` 链接中和、`meta refresh` 删除；且**不动** `data:`/`http(s)` 资源
- 链接改写：本地链接换成惰性链接带绝对路径、远端链接加 `target=_blank`、`#frag` 保持
- 桥接脚本注入位置正确（插在 `</body>` 之前，无 `</body>` 时追加）

组件层（`HtmlFrame`、`FilePreview` 的渲染分支）按仓库测试边界人工验证，不写 TSX 测试。

## 边界与已知限制

- **IFrame 的白底**：文档没自带背景时按浏览器默认白底，不注入主题样式——预览是「文档
  原本的样子」，不是「Kalo 深色主题里的样子」。
- **外链点击不跳出**：`target=_blank` 被沙箱挡住（故意的，避免文档被外部页面顶掉）。
  要看外链就切源码复制，或「用系统程序打开」。
- **CSS 里的 `url()` / `@import` 不内联**：内联后的 CSS 已经没有自己的目录了，这类引用
  会 404（工具条提示只覆盖 `link`/`script`/`img`）。
- **文件超过 256 KB 会被截断**（`read_file_text` 的默认上限）：照常渲染，但带上
  「已截断」提示；截断的 HTML 可能缺闭合标签，浏览器会自行纠错。
- **脚本启用后的残余风险**：沙箱无同源 → 摸不到应用数据；但脚本可以发网络请求（例如把
  文档内容外传）。所以默认关，且**远端脚本一律剥掉**，只有本地内联脚本能跑。
- 双平台：路径解析同时吃 `/` 与 `\`，绝对路径识别同时认盘符与 `/`；无平台分支代码。
