# 界面风格改版（第一期：令牌层 + 首屏 + 输入框）

## 背景

目标风格：中性灰白 + 极淡边框 + 浅灰选中块的「AI 工作台」式现代桌面客户端。对比现状，kalo 的色板方向是对的
（中性灰白 + 极淡边框 + 浅灰选中块），差距集中在三件事：

1. **密度太高** —— 字号 `text-xs/text-sm` 为主，行高与内边距都比目标风格紧一档。
2. **圆角太小** —— 158 处 `rounded-md`（6px）、54 处裸 `rounded`（4px），观感偏「工程工具」。
3. **零彩色** —— 全部图标都是 `currentColor` 描边，没有任何品牌色点缀，冷。

目标风格还有两项结构性差异（最左 48px 图标 rail、右侧常驻「打开的标签」面板、去掉桌面菜单栏），
**本期不做** —— 它们要动 `App.tsx` 骨架和 `TitleBar` 的功能入口，回归面太大。

本期只做「低回归风险 + 立刻能看到效果」的部分：**令牌层 + 首屏 + 输入框**。

## 范围

| 层 | 文件 | 改什么 |
| --- | --- | --- |
| 令牌 | `tailwind.config.js` | 圆角刻度整体上调一档；新增 `elevated` / `tone-*` 语义色 |
| 令牌 | `src/index.css` | 新增 `--bg-elevated` 与 5 组 `--tone-*` 变量（亮/暗各一套） |
| 数据 | `src/lib/quick-actions.ts` | 每个快捷场景加 `icon` + `tone` 两个字段 |
| 主区 | `src/components/EmptyState.tsx` | 大标题 + 内联 Kalo 头像；快捷场景从文字 chip 改成图标卡 |
| 主区 | `src/components/InputBox.tsx` | 卡片抬升加高；工具条重排；工作目录/模型下沉成 footer；权限改自定义 chip |
| 主区 | `src/components/ModelPicker.tsx` | 触发器改成与 footer 一致的无边框 chip |

## 设计决策

### 1. 圆角走令牌，不逐个改 className

覆盖 tailwind 的 `borderRadius` 刻度，一次生效于全部 212 处用法：

```
DEFAULT 4 → 6px    md 6 → 8px    lg 8 → 12px    xl 12 → 16px    2xl 16 → 20px
```

`rounded-full` 不受影响（头像、发送按钮、spinner 仍是圆）。这是本期性价比最高的一项，
也是唯一一处「一改动全身」的地方 —— 所以只上调一档，不激进。

### 2. 输入框需要一个「抬升面」色

现状：主区 `--bg: #fff`，输入卡片用 `--bg-card: #f7f7f5`（灰卡片压在白底上）。
目标风格相反 —— **白卡片 + 极淡边框 + 柔和投影**，浮在白底上。

新增 `--bg-elevated`：亮色 `#ffffff`，暗色 `#262626`（比 `--bg-card: #212121` 再亮一档）。
输入卡片、首屏入口卡用它，配 `shadow-soft`（hover/focus 时升到 `shadow-lift`）。

**连带影响**：卡片内原本用 `bg-base`（亮色下 = 白）的附件 chip 会和白卡片糊在一起，
改用 `bg-card` 保证可见。这是本期唯一一处「必须跟着改」的连带点。

**踩坑记录**：`boxShadow` 的 key **不能和 `colors` 的 key 重名**。最初命名为
`boxShadow.card`，但 tailwind 会从色板另外派生一套 `shadow-<color>` 工具类，
`colors.card` 生成的 `.shadow-card{--tw-shadow: var(--tw-shadow-colored)}` 排在后面，
按层叠顺序**覆盖**掉自定义阴影 —— 编译不报错，阴影静默消失。故改名 `soft` / `lift`。

### 3. 彩色只进图标，不进文字和主色

新增 5 组 tone 变量，每组两个值：`--tone-x`（图标描边色）和 `--tone-x-soft`（图标底片色）。

| tone | 用在 | 亮色 |
| --- | --- | --- |
| blue | 在线调研 | `#2f6fed` / `#eaf1fe` |
| green | 市场风向 | `#12a150` / `#e7f7ee` |
| orange | 看财报 | `#e07b1a` / `#fdf1e3` |
| violet | 精读论文 | `#7a5af8` / `#f0ecfe` |
| pink | 记到知识库 / 跑实验 | `#e0489b` / `#fdecf5` |

`--accent` 仍是黑/白（文字色）—— 主按钮、选中态不引入品牌色，保持克制。

### 4. 快捷场景：领域知识留在数据表

`quick-actions.ts` 的既有约定是「这里是数据不是逻辑」。所以图标不写成 JSX 塞进数据表，
而是加一个 `icon` 字符串 key，由 `EmptyState` 侧的 `ICONS` 映射表渲染成 SVG。
加一个场景仍然只改数据表一行。

### 5. 输入框信息分层

目标风格把「能力开关」和「上下文信息」分成两层，kalo 现在全挤在一条工具条里。改成：

```
┌─ 卡片（bg-elevated, rounded-2xl, shadow） ─────────────┐
│  textarea（min-h 56px, 15px）                          │
│  ＋   [⚠ 全部放行 ▾]   ◔          @目录名        （↑）│
└────────────────────────────────────────────────────────┘
   📁 工作目录          Doubao Seed Evolving ▾            ← footer，卡片外
```

- 模型选择器从拥挤的工具条**下沉到 footer**，和工作目录同排 —— 对应目标风格的
  `默认工作空间 · Doubao Seed Evolving` 那条。
- 工具条右端新增 `@目录名` 作用域标签（对应目标风格的 `@默认工作空间`），只在有 cwd 时出现。
- 权限从原生 `<select>` 换成自定义 chip 下拉：原生 select 在 Windows 上无法去掉系统外观，
  和目标风格的「⚠ 全部允许 ▾」差距最明显。行为不变（两个选项、同一个 `setSteeringMode`）。

### 6. 宽度不动

`MessageList`、`TodoPanel`、`InputBox` 三者都是 `max-w-3xl`，是对齐关系。目标风格的输入框更宽，
但要动就得三个一起动，收益不抵风险。本期保持 `max-w-3xl`。

## 不做（留给第二期）

- 最左 48px 图标 rail
- 右侧常驻「打开的标签」面板（现状 `FilePanel` 是按需弹出）
- 去掉 `TitleBar` 的「文件/视图/帮助」菜单栏，换成左上工作区切换器
  —— 菜单里的选目录/切主题/切页面是唯一入口之一，得先找到落点
- 侧栏分组标题的计数与 hover 工具按钮
- 图标资产统一（现在是手写 14px 描边 SVG，目标风格是 16-18px 彩色）

## 回归风险

| 风险 | 缓解 |
| --- | --- |
| 圆角令牌全局生效，可能撞到某处依赖 4/6px 的紧凑布局 | 只上调一档；`rounded-full` 不受影响 |
| `bg-elevated` 让卡片内 `bg-base` 元素失去对比 | 已定位到附件 chip 一处，同步改 `bg-card` |
| 权限 chip 替换原生 select | 自包含组件，选项与回调完全照搬 |
| 暗色模式 | tone 变量与 `--bg-elevated` 都写两套；`.dark` 下 soft 底片用低透明度实色 |
