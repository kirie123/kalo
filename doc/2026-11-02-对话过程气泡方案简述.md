# Kalo 对话过程气泡方案简述

## 核心体验

对话采用「正文常驻、过程可折叠、结果可回看」的结构。执行过程中展示正在做什么和已运行多久；完成后，过程气泡自动收成一行耗时摘要，让最终回复与交付物成为阅读重点。用户随时可以展开过程检查工具输出。

这里的“气泡”是轻量活动组，不是每一步都套一张有边框的卡片。

## 运行到完成的状态变化

```text
运行中（默认展开）
◌ 搜索资料，读取文件 · 已运行 12 秒  ▾
    搜索：行业最新进展
    读取：研究笔记.md

完成后（自动收起）
用时 1 分钟 13 秒  ▸

助手的解释与最终回复继续显示在下方……
[报告文件]  [可视化成果]

点击回看（手动展开）
用时 1 分钟 13 秒  ▾
    搜索：行业最新进展
    读取：研究笔记.md
```

- **运行中**：尾部活动组默认展开，组头显示小型运行指示、动作摘要、已运行时间与箭头；有可靠起始时间时每秒更新一次。动作摘要最多列三类，完整摘要可悬停查看。
- **阶段完成**：后续助手正文出现时，前一活动组自动收起；组内仍有并发工具运行时保持运行态。本轮结束后，各过程组默认收起。
- **完成态**：移除运行指示和动作计数，仅保留「用时 N 秒／N 分钟 N 秒」与展开箭头。耗时冻结，不随展开、主题切换或重渲染增长。
- **历史记录**：默认收起；缺少可靠结束时间时显示「任务过程」，不能把用户打开页面后的停留时间当成执行耗时。
- **用户控制**：运行中与完成后都可以手动展开或收起；同一阶段的流式更新不覆盖手动选择，运行阶段变化时才重置默认状态。
- **失败状态**：收起后仍显示「含失败步骤」，展开可读原始错误。耗时摘要只表示过程结束，不代表所有步骤成功。

“已处理 XX 秒”表达的是同一类时间反馈；当前界面实际文案为运行中「已运行 XX 秒」、结束后「用时 XX 秒」。时间按活动段计算，不冒充整轮任务总耗时；当前完成时间来自界面观察到的结束时刻，未作为历史结束时间持久化。

## 哪些内容折叠

连续工具调用和仅含思考的条目组成一个活动组。助手正文、用户输入、错误、中止、重试、压缩提示、文件改动及交付物切断分组，按原顺序展示。

自动收起的是执行过程；助手的阶段说明、最终回复和交付物始终留在画布上。含正文与思考的消息保留原有块顺序，其中思考过程可独立展开。呈现文件的成功操作不重复生成工具行，失败时仍保留诊断入口。

## 关键设计语言

| 部分 | 样式与节奏 |
| --- | --- |
| 助手正文 | 直接铺在阅读画布上，15px，Markdown 行高 1.75，消息外层行高 1.8；消息上下间距 4px / 10px |
| 活动组 | 无大块背景、无通栏分隔线；上下间距 4px / 6px |
| 活动组头 | 14px，行高 1.6，次级文字色；纵向内边距 5px，元素间距 7px，宽度随内容 |
| 工具行 | 线框图标、动作与目标、必要状态；最小高度 30px，纵向内边距 4px，详情按需展开 |
| 思考详情 | 12px，行高 1.75，内边距 12px 14px，圆角 10px，弱背景；最高 24rem，超出内部滚动 |
| 数字与图标 | `font-variant-numeric: tabular-nums` 防止计时数字宽度跳动；行内 SVG `vertical-align: -.125em` |
| 深色文字 | 正文 400 → 360，中等 500 → 460，强调 600 → 560；不支持连续字重的系统字体自动取近似值 |

清昼浅色使用 `#fcfcfb` 阅读面、`#f1f1ee` 弱背景、`#6b6b6b` 次级文字；深色使用 `#151515` 阅读面、`#1a1a19` 弱背景、`#9b9b9b` 次级文字。通过微明度差与留白分层。纸间、深航复用相同结构，仅替换语义色值。

```css
.work-segment-head {
  color: var(--text-dim);
  font-size: 14px;
  line-height: 1.6;
  gap: 7px;
  padding: 5px 0;
  border: 0;
}

/* 独立思考详情的高度过渡；内层必须允许收缩并裁切。 */
.thinking-disclosure {
  display: grid;
  grid-template-rows: 0fr;
  visibility: hidden;
  transition: grid-template-rows 200ms cubic-bezier(.215, .61, .355, 1),
              visibility 200ms;
}
.thinking-disclosure[data-open="true"] {
  grid-template-rows: 1fr;
  visibility: visible;
}
.thinking-disclosure > div { min-height: 0; overflow: hidden; }
```

## 动效与可用性边界

- 独立思考详情使用 Grid 高度过渡；活动组主体沿用按需挂载与滚动锚定，避免为大量历史工具内容常驻 DOM。两者不是同一种折叠实现。
- 箭头短时旋转，点击目标有键盘焦点，组头提供 `aria-expanded`；折叠的思考正文不进入辅助阅读树。减少动态效果模式取消相应过渡与闪烁。
- 复制成功显示对勾，2.5 秒后淡出恢复；失败显示「复制失败，点击重试」，重复复制重置反馈计时。
- 流式回复不逐字模糊或排队播放。Markdown 解析间隔至少 300ms，超过 24,000 字符时暂用纯文本，结束后完整排版，优先保证输入响应。
- 分组只改变显示方式，不修改原始消息、复制内容、会话文件或引擎协议；Windows 与 macOS 共用这一套前端交互。
