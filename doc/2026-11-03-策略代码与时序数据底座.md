# 策略代码与时序数据底座

## 目标与首条验收链

从海康威视（002415.SZ）的5分钟KDJ底仓做T出发，打通免费分钟数据 → 质量检查 → 可编辑代码 → Rust事件驱动回测 → 成交/拒单/资产报告 → 助手解释与修改。ETF日线轮动继续使用原有快照与报告，禁止把股票分钟数据塞进ETF份额模型。

第一条链只开放已校验证券和周期，海康威视5分钟线为初始支持项；证券主数据、交易规则、周期、数据适配器均为显式类型。后续新增证券必须提供交易所、证券类型、交易时段、最小价格变动、买卖单位、结算规则和涨跌幅规则，不能用股票代码前缀猜全套制度。

## 分层与数据契约

1. 原始层保存供应商响应、请求参数、抓取时间和校验指纹；不修改已有原始文件，不以演示数据填补接口失败。
2. 规范层使用有版本的数据集清单，包含证券主数据、周期、时区、价格口径、数据来源、观测时间、实际覆盖、质量问题和已完成K线。K线时间采用北京时间带时区的区间结束时刻，同时记录交易日；成交量单位股、价格人民币元。价格不复权用于撮合；日线复权因子用于公司行为检测，不将事后前复权价格用于实际买卖。
3. 可用性层区分经济发生时刻与首次观测时刻。已结束价格K线可用于历史价格策略；盘中未完成K线排除。ETF份额/净值保留首次观察约束。财报、成分股及事件等未来数据必须提供发布时间和修订版本，未有这些证据不得进入历史决策。
4. 数据集与报告为不可变版本，报告保存数据哈希、引擎哈希、完整代码、参数、交易规则与费用，代码变更产生新实验。跨供应商不拼接无标记的价格序列；后续CSV/付费源必须通过相同规范化与校验入口。

分钟数据先接腾讯公开接口，窗口由供应商实际返回决定，不能宣称可获取多年分钟历史。每次保存冻结数据集，重复采集不覆盖。首尾不完整交易日标记并排除，交易日内缺失K线阻止回测，不补零、不前向填充、不靠取交集掩盖缺口。午休不视为缺口。交易日参照同标的日线日期；停牌、缺失与非交易日区分。同步同时取得原始/前复权日线，核对日内价格范围、前收盘与分红拆分；无法解释的公司行为拒绝进入撮合。

初期JSON冻结文件承担可重复性，避免为短窗口过早引入第二数据库。扩大到批量证券/多年分钟线时，在此契约下增加按证券/周期/交易日分区的列式存储与索引，元数据指向不可变分区；查询仍按数据集版本、时点和交易日裁切。存储格式不穿透策略API。

## 策略运行时与交易账本

- 使用Rust内嵌Rhai执行代码，提供 `on_bar(ctx)`。代码可写变量、条件、循环、函数和状态，返回订单意图；不拼装shell、不调用Python环境、不开放文件/网络/模块加载。限制代码大小、操作步数、调用层数、数组、字符串及状态大小，超限返回可定位错误，不能拖死桌面。
- 每根K线收盘计算指标和策略，订单仅在下一根K线开盘尝试成交。输入只能包含截至当前信号的历史窗口、KDJ、现金、总仓位、可卖仓位、底仓及显式策略状态。状态由策略返回并传入下一根，数据集未来K线和未来高低价不会传给代码。
- KDJ明确采用N周期RSV，K/D初值50，K、D按1/3递推，J=3K−2D；预热期不交易，平价区间RSV取50，参数与实现写入实验。用户可在代码中实现其他指标和交易条件。
- 初始现金与已有可卖底仓分开输入；初始资产=现金+底仓市值。买入增加当日锁定仓位，下一个交易日解锁；卖出只能扣可卖仓位。支持先卖旧仓再买回，也支持先买后卖旧仓，禁止裸卖空和卖出当日新买股份。底仓并非免费资产。
- 撮合检查整数股、100股单位、现金、可卖仓位、停牌/零成交量、涨跌停和容量。容量使用已知前一根成交量的上限，不借用下一根完整成交量。订单不自动无限挂起，跨日信号明确失效；最后一根信号无下一根成交机会，记为未成交。
- 佣金、最低佣金、卖出印花税、双边过户费、滑点分项记账；费用规则和生效日冻结。以保守撮合处理无法确定成交的涨跌停，不从K线推断排队成交。日内未回补底仓不强制虚构收盘成交，报告明确仓位偏离和隔夜敞口。
- 每根资产、仓位、可卖数量、信号、成交和拒单原因保留。基准为同等初始现金和底仓的持有组合，展示总收益与相对持有差额，不能把股价上涨全算成做T收益。

- 右栏开关移到原生标题栏，点击区不参与窗口拖动；聊天控制文件/浏览器/终端侧栏，投行控制研究助手。两个开关状态相互独立，切页保留。
- 策略入口增加代码研究页：数据集及质量、代码编辑、账户/费用、运行状态和历史实验。内置KDJ底仓做T代码可直接编辑并运行，代码与参数草稿保留；实验报告可恢复代码继续修改。
- 从行情、资金、回测和代码页带上下文提问时，显示可移除的上下文卡，携带页面、证券、快照/数据集ID、窗口/区间、报告ID和正在编辑的代码。只填入待发送上下文，不自动执行；已有问题草稿不被覆盖。切换研究对象更新待发送上下文，不改已经发出的请求。
- 桥接版本仍为1，新增明确操作：分钟数据同步、代码回测；目录新增 `datasets` 与 `scriptReports`，不改变旧 `snapshots/reports` 含义。任务仍走同一Rust工作进程、单任务槽、幂等ID、取消和会话归属。活动状态增加数据集/代码报告引用，完成后导航至代码研究页。
- Agent读取目录获得支持范围、运行时API、样例代码、数据质量与默认参数，可直接提交代码回测。报告包括完整代码供面板恢复；工具摘要保留成交/拒单与成本口径，不凭统计数量猜原因。
- 代码报告摘要包含前200笔订单、总数、截断标记及分项费用；库存规则随结果返回。卖出100股旧仓再买回100股后，1000股总仓位中仍有900股可卖，不得解释为每天只能做T一次。成交时间记录下一根区间开盘时刻，拒单成交时间为空；零实际成交的K线不撮合。

## 验收与边界

纯逻辑测试覆盖：时段与午休、日期与单位、重复/乱序/缺口、未完成K线、KDJ已知序列、T+1与底仓、现金/费用/容量/涨跌停、次根成交、跨日订单失效、未来价格不影响既有信号、脚本无限循环/非法返回/越权访问、数据与代码版本复现。
