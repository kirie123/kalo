# 对话过程与成果分层渲染

2026-10-24 修订：活动分组改为连续工具与纯思考条目，所有助手正文常驻，正文到来或本轮结算时默认收起前一段活动；运行中也可手动切换。具体规则见 [连续工具活动与对话气泡](2026-10-24-连续工具活动与对话气泡.md)。下文的整轮分组为历史设计记录。

## 目标

对话按一轮任务组织：用户输入靠右，助手正文直接排版；运行过程持续展开，完成后自动收起。进度说明与工具操作按时间顺序混排，最终回复、文件改动和可视化产物保持可见。明暗主题、Windows 与 macOS 使用同一套 React 渲染逻辑。

2026-10-21 间距修订：过程容器 gap 收为 4px、顶部 padding 收为 8px；过程内 assistant 消息不再叠加普通正文的上下 margin，折叠思考行上下 padding 各 2px。正文与用户消息间距不变，减少“思考过程”和工具调用之间的空白。

## 时间线映射

- 新增纯函数 `foldConversationTurns`，只生成视图，不修改原始 timeline、会话文件或引擎契约。
- 用户消息、改动文件卡与已记录的本轮 usage 是轮次边界；历史分页从轮中开始时，也能生成独立过程段。
- 同轮中，最后一次工具组之后的最后一条有正文且没有 toolCall、错误或中止的助手消息，作为最终回复。其余助手消息（包括进度正文）、工具组、重试、压缩记录归入过程。
- 运行中的尾轮全部保留在展开过程里，不提前把进度当成最终回复。结束后才识别最终回复。
- 最终消息混有 thinking 时，将 thinking 留在过程，正文留在外部；虚拟条目使用确定的派生 id，原始消息不变。
- 错误、中止、系统提示、widget、独立产物和文件改动留在过程外，保持可访问。工具失败同时在过程摘要中标明，用户可展开查看。
- 复制本轮回复保留既有完整正文语义；收起过程不删除消息。

## 展示与交互

- 过程段取消卡片底色、步骤计数、标签堆叠及左侧多层竖线，改成低对比标题与细分隔线。
- 运行中标题显示「正在处理」，有可靠的起始时间时显示经过时间；运行中不能折叠整个过程，但单个工具详情仍可展开。
- 实时观察到完成时，以该段最早助手/工具时间到完成时刻显示用时；重新挂载的历史没有可靠结束时间，只显示「工作过程」，不推算或伪造精确耗时。
- 过程完成后默认收起，用户可以反复展开。新一轮开始时再次强制展开，完成后重新默认收起。
- 工具组默认收为图标、自然语言动作和展开箭头；展开后按行查看命令、路径、结果、diff、子 agent 活动和终端入口。单行详情不再默认铺开 edit diff。
- 思考标题用中文，不显示字符计数；空思考块不占行。
- 最终回复增加段落留白；用户气泡使用主题中的强调前景/背景；改动卡默认展示前三个文件，余项按需展开，产物列表始终可见。
- 手动折叠补偿段头位置；自动折叠由浏览器滚动锚定与底部跟随处理。底部跟随继续遵守用户是否已经向上滚动；晚加载图片等内容通过尺寸观察保持底部跟随。

## 图片交付物

正文中的 Markdown 图片在原位置显示，段落和说明文字保持原顺序。缩略图最大宽度 320px、最大高度 240px，保持比例并使用圆角；窄窗口不溢出。点击进入全屏大图，可点遮罩、关闭按钮或 Escape 返回。只有通过产物工具交付的图片，也在产物列表展示缩略图，并保留文件行和右键操作。

图片来源解析放在纯逻辑层：支持 Windows 盘符、UNC、macOS/POSIX 绝对路径和 file URL，通过现有 readFileBytes 桥接读取；远程仅允许 HTTP(S) 与栅格图片 data URL，其他协议不加载。普通 Markdown 链接仍使用原安全策略。读取超限、文件删除或解码失败时显示可重试的错误，不能留下空白占位。沿用既有字节上限，不改引擎或 IPC 契约。不缓存跨会话的本地图片数据。历史回复重新打开时按原路径读取，文件被移动后给出明确提示。

纯函数测试覆盖两平台路径、编码与不允许协议；真实组件验证正文图片、纯产物图片、放大与关闭、读取失败、窄窗及主题。相对路径没有可靠基准时不读取，提示改用绝对路径。

Markdown 的 URI 编码在进入图片解析前还原，支持编码后的空格与 Windows 反斜杠；文件产物传入的原始路径不做 URI 解码。正文路径推荐使用正斜杠，包含空格时用尖括号包裹目标，避免 Markdown 将反斜杠识别为转义字符。

## 验证

纯函数单测覆盖进度与工具交错、结束后折叠、最终回复识别、混合 thinking、错误/中止、产物保留、多轮与历史分页、稳定 id、缺失时间戳。运行桌面端类型检查及现有纯逻辑测试。组件通过浏览器中的受控时间线验证运行、完成、展开详情、窄窗与暗色；该验证不替代原生 IPC 与真实引擎联调。

## 2026-10-20 真实引擎验收记录

### 环境与边界

重建当前 sidecar，使用已配置模型执行单文件「星际接球」小游戏任务。原生窗口截图在重新获取窗口后仍连续超时，因此使用浏览器加载同一套 ChatView、MessageList、InputBox、RightPanel 与 AgentMapModal，通过临时本地适配器转发真实 sidecar 的命令和 NDJSON 事件。模型回复、工具执行、子 agent 与生成文件均为真实运行；原生 Tauri IPC、窗口捕获与双平台原生表现不在本轮通过范围内。临时适配器不进入产品代码。

### 已观察行为

- 实际触发任务清单、后台子 agent、文件写入、读取、编辑、shell 检查和后台结果查询。
- 使用同一个 childId 续写只读代码审查，面板仍聚合为一个子 agent，显示运行步数、续写次数与 read/grep 活动。
- 主模型高思考配置下，首次工具调用前接近四分钟；期间仅有折叠思考行和运行计时，缺少阶段说明。这是实际等待体验，需要单独评估模型默认思考档位与长等待反馈。
- 实际出现一次静态检查脚本误报，命令行错误标记与输出可展开查看；主 agent 随后修订检查脚本和游戏文件。
- 游戏已在浏览器实际执行开始、方向键移动、暂停和重新开始操作，保留运行与暂停截图。该冒烟验证不等于完整玩法与设备兼容性验收。
- 运行中实际加入输入队列并切换「立即插入」，主 agent 收到后收敛修复范围。续写子 agent 审查完成并指出致命碰撞后遍历越界问题；主 agent 最小修复后，静态检查和 35 条无依赖动态断言通过。
- 收到真实 `agent_settled` 后，过程自动折叠，最终回复、三个改动文件和 HTML 产物保留在外；`present_files` 实际触发产物页签自动打开。

### 待修正的展示问题

1. 后台 `agent` 工具返回 `{background: true, queued: true, turns: 0, tokens: 0}` 时，Agent map 显示「已完成、0 步」。这是把工具调用返回当成后台工作完成；应区分派发确认与后台任务终态，并用可用的后续快照更新状态。
2. `agent_tasks` 在过程行中显示成「调用了 1 次其他工具」，没有体现「查看子任务」的含义。
3. 工具组与单次调用各需展开一次，长输出还有内部滚动区域。应减少查看单调用结果所需的层级，并避免输出区域的嵌套滚动。
4. 浏览器联调环境中，HTML 产物切换「运行文档脚本」后内嵌预览空白，而同一文件在独立浏览器页可运行。iframe 尺寸非零且已收到文档内容；原因未定，需在原生 WebView 中复核，不能直接认定为跨平台产品缺陷。
5. 主任务结束后任务清单仍有一项「进行中」；后台结果的延迟通知还使主 agent 追加了重复的完成说明。应评估完成清单的收尾提示，以及已读取后台结果的通知去重与最终回复呈现。

以上问题保留为真实验收发现；本轮不把局部渲染验收写成整条生产链路通过。

### 图片与交互可视化补充验收

使用同一套 React 组件与本地 sidecar 转发适配器，恢复上一轮真实小游戏历史，展开查看子 agent 派发参数、登记结果与命令输入输出并截图。另建独立测试会话，以会话级低思考参数实际调用 read_me 和 show_widget，生成无外部依赖的「抛物线实验室」HTML 组件；两个工具均成功返回，组件从真实会话文件恢复。

将角度滑块从 45° 改为 65° 并点击发射后，界面射程从 40.8m 变为 31.3m，最高点从 10.2m 变为 16.8m，轨迹随之变化。最终模型回复包含已有小游戏截图的绝对路径，图片在正文中按比例显示，点击打开大图，Escape 关闭后焦点回到原图片。另检查图片产物列表、暗色与缺失文件提示。修正 Markdown 将 Windows 反斜杠编码成 %5C 后无法识别路径的问题，并补纯函数用例。

本次未验证原生窗口与 macOS 实机。可视化生成期间主要显示思考/工具过程，完成的组件才出现在时间线；不将此记录描述成已经验证了渐进组件预览。现有可视化折叠会卸载 iframe，重新展开会重置交互状态，后续应评估保留状态。
