# 通用证券与分钟历史扩展

## 用户路径与界面结构

侧栏保留四个入口：总览、市场研究、策略实验、数据中心。市场研究内用局部页签切换行情、ETF 资金、两融；策略实验内切换代码策略、ETF 轮动。原有页面 ID 与工具结果定位保持有效，研究助手仍携带当前页、证券、冻结数据集和实际编辑代码。

```text
投行                 市场研究                     讨论此页
  总览               行情 / ETF 资金 / 两融
  市场研究           范围选择     数据快照
  策略实验           指标摘要
  数据中心           趋势与明细

策略实验             代码策略 / ETF 轮动
  新建实验           名称、冻结数据集、策略起点 → 创建并编写
  编辑草稿           代码编辑器                  运行回测
                     回测设置（按需展开）
  查看结果           收益曲线、指标              继续修改
                     实验记录（草稿和已完成报告）
```

两融的个券入口移入范围下拉，避免把某家公司作为永久页签。现存个券观察仍保留，名称明确为已同步证券。研究池与历史实验折叠收纳，避免导航无休止增长。

页签使用独立点击热区与内缩悬停底色：热区保持36px以上，悬停底色有横向留白与6px圆角，不触碰导航底部分隔线；选中态使用独立细线，不因悬停改变宽度或位置。键盘焦点保留可见描边，减弱动效设置下关闭过渡。投行图标沿用统一24px SVG网格、1.5px圆端线条，分别以四格总览、K线行情、实验瓶、数据库表达四个入口；助手、同步、折叠、关闭与下拉箭头同属该图标体系，替换文字字符图标。

### 策略实验的创建与阅读流程

新建默认进入自然语言入口：策略描述 → 开始研究并回测 → 右侧研究助手执行 → 主面板展示真实报告曲线。手动选择数据与模板通过“手动配置”进入，保留原流程。自然语言入口不要求已有行情、实验名称、周期或模板；上下文仅包含用户本次想法，不夹带上一实验的数据集及自动选中的证券。

### 分钟来源隔离与历史修订

复现证据：早期腾讯分钟快照只有5个交易日，后续新浪返回约40日5分钟数据。在相同时间戳上，240根重叠K线中238根成交量、127根收盘价不同，价格差异不止浮点精度。旧逻辑仅按证券与周期比较，误将跨供应商分钟差异当作同源修订，阻止已经通过日线校验的新窗口落盘。

数据集增加可选 `seriesKey` 字段，标识分钟供应商、适配版本、结束时刻与成交量单位；周期、时区、价格口径和冻结证券规则另外匹配。新新浪快照写入稳定序列键。旧快照不改写：仅对已知的新浪/腾讯来源文案兼容识别，未知来源保守隔离。维持schemaVersion=1的向后兼容扩展；Rust、桌面与Agent目录均可读取旧记录，旧报告仍绑定原始数据ID与哈希。

新下载窗口必须先通过原有OHLCV、完整交易时段、日线范围、收盘与公司行为校验，再尝试扩展。异源历史不比较数值也不拼接，记录来源隔离提示；同源仍严格比较重叠OHLCV与前收盘，不通过增加容差混合数据。遇到修订时排除整份旧候选并记录数据ID、首个冲突时间和字段，保留新窗口及其他可兼容历史，不让某份旧记录永久阻断新同步。

候选按结束时间、采集时间、ID确定性排序。每次合并先在副本上完成，重新按日线证据验证交易日连续性、盘中完整性与价格范围；验证失败、无重叠或超出10000根限制的候选不能污染已接受结果。旧数据不在当前日线证据覆盖内时不猜测拼接。损坏的历史文件单独提示并隔离，不影响已校验的新窗口。新数据独立生成ID，记录合并来源原始证据与序列键哈希，旧快照和旧报告文件逐字节保留。

实际覆盖始终展示在数据选择和报告中：5分钟约40日，15/30/60分钟按免费源真实覆盖扩展，本地同源连续历史可继续积累。遇到公司行为时明确可回测区间，不把约两年行情误称为可跨分红的连续账务回测。验收需在含原腾讯5日快照的真实数据目录中同步海康5分钟和更大周期、运行Rust策略、重复同步验证稳定性，并校验旧文件哈希不变。

## 撮合与验证

### 公司行为账务扩展

目标是让已核实分红送转的分钟历史连续回测，不再要求手动拆区间。沿用不可变数据集、原始价格撮合与原始证据存档；增加可选corporateActions数组，缺字段的旧快照仍按原隔离日期保护，重新同步才获得新账务数据。公司行为从免费实施明细获取每股税前现金、送股、转增、登记日、除权日及公告日期，现金到账日期由实施日历匹配，送转上市日从同一实施公告提取，不用除权日代替未知到账/上市日。原始响应、公告标识及来源随快照冻结；取消/预案、重复冲突、日期或金额缺失、日线因子与方案不符均保留隔离原因。未解释的复权跳变、配股及其他未支持事件继续拦截，不能仅删除门禁。

回测以登记日收盘的实际持仓确定权益，包含当日买入但未可卖库存；登记日卖出部分不再享权。除权日开盘前增加应收股息与待上市股份，支付日转为现金，股份上市日解锁；应收与待上市股份计入总资产但不能用于买入/卖出。初始底仓仅从回测开始时起拥有，不补发开始前登记的股息；开始时已存在但尚未处理的权益无法从数量推断，非零底仓遇到该边界明确要求更早起点。持有基准使用独立同规则账户，不静态计算初始股数乘现价。已知公司行为日以除权参考价计算涨跌停；原始行情不改写。

现金按分记账，送转保持总成本不变、重算每股平均成本；现金分红单列收入，不同时冲减持仓成本造成收益重复。新增股份在上市前单独计量并分配成本，卖出按移动平均成本确认已实现盈亏，买入含交易费用进入成本。零股仅允许一次性卖出全部可卖零股，不能按买入整手规则丢弃。由于真实零碎送股取决于全市场排序分配，无法确认整数权益时明确拒绝该次回测，不捏造现金补偿或随机舍入。
