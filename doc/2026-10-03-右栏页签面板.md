# 右栏页签面板（文件 / 浏览器 / 终端）

日期：2026-10-03
状态：已实现
相关：`doc/2026-10-02-桌面终端与长命令实时可见.md`（终端与长命令可见性的第一部分；本文替换其
「文件 / 终端」互斥视图的交互）

## 0. 背景

第一版把右栏做成了两个互斥视图（顶栏两个按钮切「文件 / 终端」）。实际使用下来这个形态不对：
终端应该是**右栏里的一个页签**，和文件浏览并列存在，而不是另一个视图。参考形态是「+ 菜单
（文件 / 浏览器 / 终端）+ 页签条」：打开的每一件事物都占一个页签。

本文把这个交互定下来，并补上「浏览器页签」。

## 1. 目标与非目标

**目标**

1. 右栏 = 一个页签容器：顶部页签条（页签 + `+` 菜单），下方是当前页签的内容。
2. 页签四种：**文件**（目录树 + 文件预览）、**浏览器**（地址栏 + 页面）、**终端**（真 shell）、
   **跟随**（某条 bash 命令的只读镜像）。
3. `+` 菜单：文件 / 浏览器 / 终端。
4. bash 工具行的「在终端中打开」→ 新增或激活对应跟随页签，并展开右栏。
5. 顶栏只留一个「右栏面板」开关；视图菜单同样只留一项。

**非目标**

- 浏览器页签是**内嵌 iframe**，不是内嵌系统 webview：不做前进/后退（跨域读不到 history）、
  不做多窗口、不做开发者工具。
- 页签不持久化：重启后回到「只有一个文件页签」。
- 不改引擎/sidecar 契约，不需要重建 `pi-*.exe`。

## 2. 交互

### 2.1 页签条与 `+` 菜单

- 页签条固定在右栏顶部：`[文件] [浏览器 ▸ 标题] [终端] [跟随 ▸ 命令摘要 ×] … [+]`。
- 页签标题：文件页签固定「文件」；浏览器页签取域名（空地址取「浏览器」）；终端页签「终端」；
  跟随页签取命令摘要，运行中带一个小绿点（结束后换成眼睛图标），tooltip 显示完整命令。
- `+` 菜单三项：
  - **文件**：激活文件页签（文件页签唯一，不会重复添加）。
  - **浏览器**：新建浏览器页签并聚焦地址栏；同 URL 的浏览器页签只激活不重复建。
  - **终端**：新建一个 shell 页签（cwd = 当前会话工作目录）。
- 关闭：文件页签**不可关闭**（没有 ×）；其它页签有 ×。
  - 关终端页签 = kill 对应 PTY（沿用 `terminal-session` 的卸载收尾）。
  - 关跟随页签 = 清掉 watch 注册表里的条目（工具行上仍持有自己的副本，再点还能重开）。
  - 关浏览器页签 = 仅移除。
- 页签条横向可滚动；激活页签用 `bg-card` 高亮。

### 2.2 宽度与显隐

- 整块右栏一条左缘拖手（`chat | 右栏`），宽度记在 `kalo.layout.panelW`（默认 640，min 320，
  max 1400）；**所有页签共用**这一个宽度，切页签不会再跳宽度。
- 隐藏用 CSS（`hidden`），不卸载：终端的 xterm 缓冲与 shell 进程、浏览器的页面都留着。
- 入口：顶栏「右栏面板」按钮 + 视图菜单「右栏面板」一项（两者等价）。

### 2.3 文件页签

沿用原有文件面板（目录树 / 路径栏 / git 状态 / 变更列表 / 产物 / 预览），只改两处布局：

- 树列保持固定宽度（`kalo.layout.treeW`，与预览列之间有拖手）；**预览列占剩余宽度**
  （原来是固定宽 `previewW`，现在由右栏宽度决定）。
- 没有打开预览时，树列占满整个右栏（不再留一条空列）。
- 全屏预览仍是覆盖整窗的 overlay（Esc 退出）。

### 2.4 浏览器页签

- 顶部一条地址栏：按钮为「重新加载」「在系统浏览器打开」（浏览器里没有后退——跨域拿不到
  history）；地址栏回车导航，Esc 撤回上一地址。
- 地址归一化：空 → 什么都不做；没有 scheme → 补 `http://`（`localhost:3000` 直接可用）；
  已知 scheme（`http/https/file/about/data/…`）或带 `//` 的 → 原样。
- 页面是 `<iframe>`，`sandbox` 允许脚本 / 同源 / 表单 / 弹窗 / 下载，`referrerPolicy=no-referrer`。
- 空地址时显示提示：输入网址回车打开，本地服务（如 `http://localhost:3000`）可直接预览；
  部分站点用 `X-Frame-Options` / CSP 拒绝被嵌入，会显示空白 —— 用「在系统浏览器打开」。
- 「在系统浏览器打开」走桌面端已有的 `open_path`。URL 不参与 Windows 的反斜杠改写
  （本次顺带修掉了 `http://…` 被写成 `http:\\…` 打不开的问题，`files.rs::is_url`，带单测）。

### 2.5 跟随页签（bash 镜像）

与第一版一致：只读（`disableStdin`），第一行是命令回显，其后是实时输出，结束追加一行灰色提示；
命令跑完页签保留当日志。数据来自 `tool-watch-registry`（chat-store 发布，只有 bash 发布）。

## 3. 状态与代码结构

### 3.1 页签模型（新 `lib/panel-tabs.ts`，替换 `lib/terminal-panel.ts`）

| 字段 | 说明 |
|---|---|
| `open` | 整块右栏是否展开 |
| `tabs` | 页签数组，第一项恒为文件页签 |
| `activeId` | 当前页签 id（文件页签 id 固定 `files`） |

页签类型：

| kind | 字段 | 说明 |
|---|---|---|
| `files` | — | 恒存在、不可关、不重复 |
| `browser` | `url` | URL 存在 store 里（地址栏与页签标题共用） |
| `shell` | `cwd` | 真终端 |
| `watch` | `toolCallId` / `command` | bash 只读镜像，按 `toolCallId` 去重 |

纯 reducer（单测覆盖）：`togglePanel` / `activateTab` / `closeTab` / `addTab`（含文件不重复、
跟随按 toolCallId 去重、浏览器按 url 去重、shell 永远新建）/ `setTabUrl`。单例 `panelTabs` 只做
「state + notify + watch 注册表 seed/clear」这层胶水，与 chatStore 的形态一致。

### 3.2 URL 工具（新 `lib/browser-url.ts`）

`normalizeUrl(input)`：返回 `string | null`（null = 空输入）；`browserTitle(url)`：取 host，
空/失败时回退「浏览器」。纯逻辑，单测覆盖。

### 3.3 组件

- 新 `components/RightPanel.tsx`：左缘拖手 + 页签条（含 `+` 菜单，复用 `ContextMenu`）+
  内容区；非激活页签 `hidden` 但保持挂载。
- 新 `components/BrowserTab.tsx`：地址栏 + iframe + 空态提示。
- `components/FilePanel.tsx`：去掉自带的 `aside` 外壳与左缘拖手，预览列改为占剩余宽度，
  树列在无预览时占满。
- `components/TerminalTab.tsx` / `TerminalWatchTab.tsx` / `xterm.ts`：不变。
- 删除 `components/TerminalPanel.tsx`（被 RightPanel 取代）。
- `App.tsx`：`usePanelTabs()`；顶栏一个面板按钮；视图菜单一项。
- `ToolCallGroup.tsx`：bash 行的「在终端中打开」调 `panelTabs.openWatchTab(...)`。

### 3.4 不变的部分

`terminal.rs`（PTY）、`terminal-session.ts`、`terminal-watch.ts`、`tool-watch-registry.ts`、
`tool-output.ts::contentText`、`chat-store` 的 `startedAt` 与两处发布，全部沿用。

## 4. 双平台

iframe 与地址栏无平台差异；`open_path` 封装了平台差异（Windows `cmd /c start`、macOS `open`、
Linux `xdg-open`），本次只补了「URL 不改写分隔符」这一条。本页签面板不引入新的 OS 分支。

## 5. 测试

- **vitest（纯逻辑）**：`panel-tabs`（开关/激活/关闭回落/去重规则/URL 更新）、
  `browser-url`（归一化与标题）。原有的 `terminal-panel.test.ts` 迁移为 `panel-tabs.test.ts`。
- **cargo test**：`files.rs::is_url`（URL 不参与 Windows 路径改写）。
- **人工验证**：`+` 菜单三项都可达；文件页签无 ×；关终端页签进程死掉；关跟随页签再点
  「在终端中打开」还能重开；切页签不丢终端滚动内容与浏览器页面；隐藏右栏再展开这些还在；
  跟随页签在切会话后仍刷新；浏览器页签打开 `http://localhost:<port>` 能显示、点「在系统浏览器
  打开」能拉起系统浏览器。

## 6. 已知限制

- 浏览器页签受 `X-Frame-Options` / `frame-ancestors` 限制，被拒站点显示空白（有提示与外部打开）。
- 浏览器页签没有前进/后退（跨域拿不到 history），只有重新加载。
- 页签不持久化：重启后只剩文件页签；终端页签里的 shell 也随进程退出。
