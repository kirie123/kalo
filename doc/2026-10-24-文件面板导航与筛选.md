# 文件面板导航与筛选

## 布局与交互

- 右栏保持打开的文件页签、浏览器、终端和跟随页签。文件页签使用细边框与圆角，补充可访问的选中和关闭名称；页签条右端提供文件树按钮，任何页签下都能返回文件区，不必先关闭终端或浏览器。
- 阅读区始终在左、目录树始终在右，不随面板宽度或系统缩放改成上下排列。文件树可收起，按会话记忆；没有打开文件时总能看到文件树。目录树最多占面板 42%，默认 240px；窄面板可以手动收起文件树或全屏阅读，不能将树放到正文下方。原有拖动列宽、全屏与 Escape 退出保留。
- 阅读区标题行显示可横向滚动的路径面包屑、内容/更改切换、全屏与关闭。点击目录段回到该目录并显示文件树；溢出菜单提供打开文件、显示位置、复制路径和添加到对话。全文预览与文档链接沿用既有文件渲染器。
- 文件树提供工作区标题、刷新、收起全部、路径输入和文件名筛选。完整目录的筛选复用既有 `search_files`：延迟 180ms、忽略过期响应、最多显示 20 项，并明确提示缩小关键词；搜索范围、跳过隐藏/构建目录和遍历上限保持后端现有行为。不把结果数当成全仓文件数。
- 变更视图按目录层级呈现并默认展开，显示状态与增删行数，目录可收起；筛选匹配已有变更的相对路径。未跟踪目录作为目录导航，不能误当成可预览文件。普通目录树、搜索结果、变更条目均显示当前打开文件的选中背景。
- 产物、右键菜单、按会话文件记忆、路径输入后退/上级导航、差异预览保留。刷新目录与 Git、切会话/工作目录时屏蔽较早请求，避免旧快照覆盖新界面。

## 分层与平台

- 文件名、父目录、面包屑与变更树构造放在纯逻辑模块，覆盖 Windows 盘符/UNC 与 macOS POSIX 根目录，不改原有路径身份规则。
- 目录树和变更树独立为展示组件，文件面板负责数据读取、会话状态和导航。新增 CSS 使用语义令牌，三套皮肤共用布局。
- 不新增或修改 Rust/引擎通信命令，不改变磁盘文件，不新增外部依赖。
