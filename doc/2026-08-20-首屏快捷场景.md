# 首屏快捷场景按钮

日期：2026-08-20
状态：已实施

## 需求

空会话首屏只有一个标题和输入框。第一次用的人面对空输入框不知道能问什么——
Kalo 已经装了七八个内置 skill，但它们的存在感是零，除非用户恰好问对了话。

要的东西很小：**输入框下面几个能直接点的场景入口。**

## 做法

一排 chip，点一下把预置提示**填进输入框**，不直接发送。

填而不发是刻意的：多数场景还要补一个参数（股票代码、论文链接、调研题目），
直接发出去只会得到一句"请告诉我你要看哪只股票"。填进去之后光标自动落在末尾，
用户补完按回车就走——比"直接发送"少一个来回。

复用已有的 `inputDraft` 通道（原本是扩展的 `set_editor_text` 用的），
新增一个 `chatStore.setInputDraft()`，`InputBox` 那边顺手补上聚焦与光标置尾。

## 场景清单是数据不是代码

清单放在 `kalo-desktop/src/lib/quick-actions.ts`，一个 `{label, prompt}` 数组；
`EmptyState` 只负责把它渲染成 chip。加一个场景加一行，不用碰组件。

这是 [roadmap §7](2026-08-17-personal-agent-roadmap.md) 那条原则的落实：
**领域知识只出现在提示与目录约定里，不该长进组件代码。** 组件不知道什么是
"宏观风向"，它只知道怎么渲染一个 label 和一个 prompt。

首批六个，对着已装的 skill 选：市场风向 / 看财报 / 精读论文 / 在线调研 /
记到知识库 / 跑实验队列。

## 后续

场景列表目前是内置的。如果以后想让用户自定义，自然的做法是读
`~/.kalo/quick-actions.json` 覆盖默认表——但在真有人提出来之前不做。
