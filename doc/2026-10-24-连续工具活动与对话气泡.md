# 连续工具活动与对话气泡

## 布局

助手说明和最终回复直接排在对话画布中，始终可见。连续的工具调用、仅含思考的助手条目组成独立活动组；助手正文、重试、压缩、系统提示、用户消息、文件改动和交付物切断分组，保持原始顺序。含正文和思考的消息保留原有块顺序，思考仍可单独展开。空的工具调用占位不显示；usage 页脚保留。

组头使用线框图标、动作摘要和右侧小箭头，不加卡片背景或通栏分隔线。摘要按首次出现顺序归并动作，最多显示三类，完整摘要在标题提示中可读。工具行只显示图标、动作与目标、已有 diff 增减数和运行状态；点击调用行展开既有输出、diff、任务清单或子任务活动。工具组内不再增加同类工具的标题层。

## 折叠状态

- 尾部活动组在本轮运行中默认展开；后续正文出现时，该组自动收起。若其中仍有运行中的并发工具，保持默认展开，直到工具完成或本轮结算。
- 本轮结算后所有活动组默认收起；历史记录默认收起。单个工具也使用相同规则，不留下无法整体收起的长输出。
- 运行中和完成后均允许手动展开或收起；同一运行阶段中的流式更新不覆盖手动选择。阶段变化时重置为该阶段的默认状态。
- 失败步骤不伪装为成功：收起后的组头保留“含失败步骤”，展开后可读原始错误。错误、中止、重试提示和产物不纳入活动组。
- 起始时间只用可靠的记录时间；历史缺少结束时间时不推算耗时。手动切换继续使用现有滚动锚定补偿，自动收起沿用底部跟随。

## 2026-10-26 产物工具提示与间距修订

- `present_files` 运行中和成功时不生成工具调用行，也不计入活动组摘要；工具组过滤后为空时不生成活动组，避免“呈现 N 个产物”插入回复正文。失败调用仍保留在活动组中，提供失败标记和可展开的错误详情。
- 过滤只作用于 `foldConversationTurns` 的展示投影，保留原始记录、产物卡片、改动文件卡、文件面板和自动打开行为。混合工具组只移除对应调用；正文与思考的原有块顺序不变，产物调用前后的正文始终在活动折叠区外。
- 活动组上下 margin 收为 4px / 6px，助手消息上下 margin 收为 4px / 10px；思考行上下 margin 和按钮 padding 各收为 2px。正文段内排版与用户气泡间距保持原样，三套皮肤、Windows/macOS 共用样式。
- 纯函数回归覆盖运行中/完成/历史的产物提示隐藏、前后正文可见、混合工具组、失败可见、产物保留与输入不变性；类型检查与桌面端纯逻辑测试验证逻辑，组件预览检查间距。

本次验证：`npm run check` 通过（类型检查、59 个测试文件共 757 项测试）。浏览器中以受控时间线加载实际组件，确认产物调用前后正文均可见、无“呈现产物”工具行、普通工具组可展开；检查清昼、纸间、深航及 360px 内容栏的间距和换行。未覆盖原生 WebView 与 macOS 实机。

## 实现边界

### 完成后的耗时摘要（2026-10-26）

活动段完成后自动收起，组头直接显示“用时 N 分钟 N 秒”和右侧展开箭头，去掉完成态工具图标与动作计数；完整动作摘要保留在悬浮提示中，展开后仍可查看调用详情。运行中显示动作摘要与“已运行”时间，运行阶段切换时沿用原有默认展开/收起规则，同阶段更新保留手动选择。失败段继续显示“含失败步骤”。

耗时使用该活动段的可靠起始时间与组件观察到的完成时间，完成后固定，不随展开、主题切换或重渲染增长。历史或重新挂载后缺少可靠结束时间时显示“任务过程”，不以打开页面的时间冒充执行结束时间。没有有效时间戳、负值或非有限值时也不显示耗时。正文仍留在折叠区外，不恢复整轮正文归入过程的旧规则；不改会话数据与引擎契约。Windows/macOS 共用组件与样式。

纯函数测试覆盖运行/完成的标题、分钟秒格式和缺失/无效耗时；组件截图验收覆盖运行转完成自动收起、73 秒摘要、展开后正文完整、手动展开稳定、失败标记与暗色窄栏。

验收结果：`npm run check` 通过（类型检查、59 个测试文件共 762 项测试）。浏览器使用实际组件和演示记录，从展开的运行态切换到完成态后自动收起，显示“用时 1 分钟 13 秒”；手动展开后切换明暗、360px 内容栏和失败状态，展开状态与耗时保持，失败详情可单击查看，产物调用前后正文始终可见。已保存完成态与暗色窄栏展开态截图；73 秒为验收输入，不是真实模型执行计时。本次未覆盖原生 WebView 和 macOS 实机。

`foldConversationTurns` 只生成连续活动的视图，原始 timeline、复制内容、会话文件和 sidecar 契约不变。`WorkSegment` 负责组级交互，工具行复用既有 `ToolCallList`，不再渲染同类组摘要。样式使用语义 token，清昼、纸间、深航共享结构；Windows/macOS 使用相同 React 逻辑，无平台路径或原生命令改动。

本方案替代 2026-10-20 方案中“整轮进度正文归入过程”的规则，其余图片、交付物与可视化保活约定保留。
