# 连续工具活动与对话气泡

## 布局

助手说明和最终回复直接排在对话画布中，始终可见。连续的工具调用、仅含思考的助手条目组成独立活动组；助手正文、重试、压缩、系统提示、用户消息、文件改动和交付物切断分组，保持原始顺序。含正文和思考的消息保留原有块顺序，思考仍可单独展开。空的工具调用占位不显示；usage 页脚保留。

组头使用线框图标、动作摘要和右侧小箭头，不加卡片背景或通栏分隔线。摘要按首次出现顺序归并动作，最多显示三类，完整摘要在标题提示中可读。工具行只显示图标、动作与目标、已有 diff 增减数和运行状态；点击调用行展开既有输出、diff、任务清单或子任务活动。工具组内不再增加同类工具的标题层。

## 折叠状态

- 尾部活动组在本轮运行中默认展开；后续正文出现时，该组自动收起。若其中仍有运行中的并发工具，保持默认展开，直到工具完成或本轮结算。
- 本轮结算后所有活动组默认收起；历史记录默认收起。单个工具也使用相同规则，不留下无法整体收起的长输出。
- 运行中和完成后均允许手动展开或收起；同一运行阶段中的流式更新不覆盖手动选择。阶段变化时重置为该阶段的默认状态。
- 失败步骤不伪装为成功：收起后的组头保留“含失败步骤”，展开后可读原始错误。错误、中止、重试提示和产物不纳入活动组。
- 起始时间只用可靠的记录时间；历史缺少结束时间时不推算耗时。手动切换继续使用现有滚动锚定补偿，自动收起沿用底部跟随。

## 实现边界

`foldConversationTurns` 只生成连续活动的视图，原始 timeline、复制内容、会话文件和 sidecar 契约不变。`WorkSegment` 负责组级交互，工具行复用既有 `ToolCallList`，不再渲染同类组摘要。样式使用语义 token，清昼、纸间、深航共享结构；Windows/macOS 使用相同 React 逻辑，无平台路径或原生命令改动。

本方案替代 2026-10-20 方案中“整轮进度正文归入过程”的规则，其余图片、交付物与可视化保活约定保留。

## 验证

纯函数测试覆盖连续分组、正文边界、空占位、混合思考、usage、多轮、历史分页、并发工具、错误与交付物顺序和输入不变性。通过真实 React 组件的浏览器预览检查自动收起、手动切换、单行详情、键盘交互、流式更新、三套皮肤与窄窗。此检查不替代原生 WebView 和 macOS 实机验收。

本次验收：桌面端类型检查及 55 个测试文件、733 项纯逻辑测试通过，文件行数与桥接契约检查通过。受控时间线加载实际 WorkSegment、TimelineItem 和工具详情组件：命令输出单击可见；运行中手动收起后更新进度不会重开；Enter 切换可用；完成后自动收起；手动展开完成组后更新不会关闭；历史重载默认收起；失败组摘要与错误详情可读。清昼、纸间、深航在 1120、600、360px 三种宽度均无横向溢出，预览无页面脚本异常。该预览使用演示记录，不调用真实模型或 Tauri IPC。

Vite 生产构建通过；现有主包体积告警仍存在，本次不扩展到拆包改造。
