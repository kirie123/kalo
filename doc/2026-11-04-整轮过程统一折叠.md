# 整轮过程统一折叠

## 展示契约

一轮执行只生成一个过程组。中途说明、思考、工具调用、重试和压缩提示都放进同一个组，助手文字不再切断过程。运行期间默认展开，整轮结算后自动收起，仅展示一条中性「用时…」和最终回复。手动展开可完整回看，同阶段流式更新不覆盖用户选择。

以用户消息、结算 usage、文件改动结算卡划分轮次。运行中的尾轮不提前把最后一段文字判为最终回复；结束后取最后一条有正文、非工具调用、非失败的助手消息作为最终回复。其思考部分仍放进过程，正文与 usage 留在外面。工具调用前的说明不充当最终回复。没有最终正文时保留过程入口和已有结束状态，不伪造答案。

产物与可视化继续在过程外常驻，保持可访问与保活，不被收起销毁。组内过程顺序不变，原始 timeline、复制内容与会话文件不变。未被重试接管的最终失败或中止仍可见；可恢复的中间错误留在过程详情中。移除组头可视及辅助名称中的「含失败步骤」，不删除原始工具错误详情。

## 样式与计时

沿用 14px 次级文字、无卡片描边的组头与箭头；运行态显示活动摘要及已运行时间，结束后去掉运行指示，耗时冻结。耗时从本轮最早可靠的助手/工具时间开始，结束沿用界面观察到的结算时刻；历史缺失可靠结束时间显示「任务过程」。不从查看历史的时间推算耗时。

Windows 与 macOS 共用纯前端投影与组件，不改变 IPC、路径或安装契约。纯函数回归覆盖中途文字不断组、运行到结算、最终思考拆分、多轮/自主轮次、失败重试、无最终回复、产物常驻和输入不可变；类型检查与前端测试验证。

## 文档取代关系

本方案取代 2026-10-24 和 2026-11-02 对话方案中「所有正文常驻、正文切断分组」的规则。仅最终回复常驻，中间正文随整轮过程收起。
