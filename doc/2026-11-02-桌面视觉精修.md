# 桌面视觉精修

## 目标与范围

保留清昼统一布局、三套皮肤、导航位置与对话数据流。优先精修应用外壳、首屏、输入区、思考过程与复制反馈；颜色和字重统一由语义变量驱动。不调整引擎通信、文件安装、窗口拖动、分栏拖拽或原生快捷键。

## 视觉方案

- 清昼浅色使用 `#f5f5f3` 外壳、`#fcfcfb` 主阅读面、`#f1f1ee` 内容卡片和抬升输入面；深色使用 `#0b0b0a` 外壳、`#151515` 阅读面、`#1a1a19` 卡片、`#20201e` 输入面。相邻表面通过轻微明度差分层，取消外壳与首屏快捷入口的装饰性边框。
- 保留表格、代码、错误状态、选择状态所需的边界，不能全局删除边框。纸间保留暖纸与绿色，深航保留墨蓝与薄荷色。
- 输入卡片常态使用轻微内阴影，聚焦时使用一细一宽的双环阴影。侧栏搜索和带边框的独立文本输入使用同一聚焦变量。按钮与链接保留清晰的键盘焦点，强制对比度模式恢复系统描边。
- 字重使用正文 400、中等 500、强调 600、加粗 700 四级语义变量；深色各减 40。系统字体不支持连续字重时由浏览器选择最近可用字重，不额外下载字体。数字启用等宽数字，行内图标按文字基线微调，正文启用 `text-wrap: pretty`，代码保持原始排版。
- 首屏使用独立品牌标识、标题、简短说明与六个轻量入口；宽度不足时自动换列，矮窗口允许垂直滚动。

## 交互方案

- 思考过程使用 CSS Grid `0fr → 1fr` 动画，不测量内容高度；折叠时内容不可访问，展开后保留原有滚动区域。正文、工具过程的自动折叠和滚动锚点保持既有行为。
- 复制按钮维持固定尺寸，成功图标轻微弹入，2.5 秒后淡出恢复；重复复制重置计时，卸载清理计时，失败显示可见且可重试的状态。为图标按钮补充辅助名称和状态播报。
- 流式 Markdown 保留已有节流与长文本降级，不给每个字符创建 DOM 或排队延迟。当前实现有长输出阻塞输入的历史证据，因此本次不应用逐字模糊；不重播已经显示的回复。
- 分栏拖拽继续直接跟随指针，不引入弹簧依赖或惯性。常规悬停、折叠采用短时减速曲线，只有复制成功反馈允许轻微回弹。
- `prefers-reduced-motion` 下取消本次位移动画、折叠过渡以及现有光标闪烁和工作圆点位移；状态仍以静态文字、图标显示。

## 平台与验证

全部改动在 React/CSS 展示层，Windows WebView2 与 macOS WKWebView 共用实现。Grid、CSS 自定义属性为基础能力；`text-wrap: pretty` 不支持时自然退回普通换行。无路径、shell、进程、资源定位或权限变更。

不为样式或 DOM 创建模拟单测。运行前端类型检查和生产构建；通过实际组件浏览器预览检查三套皮肤、明暗模式、窄窗口、键盘焦点、思考折叠、复制成功/失败与减少动态效果。原生窗口与系统字体的双平台最终观感仍需实机验收。

- 前端 TypeScript 检查、Vite 生产构建通过；构建保留现有大资源包提示，本次未增加依赖。
