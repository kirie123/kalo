# 对话用户输入刻度导航

## 交互

对话滚动区域右侧增加一列细刻度，每条代表一条已加载的用户输入，当前阅读轮次用强调色标记。两条及以上输入时显示；历史还有更早页面时，即使当前不足两条也保留入口。刻度浮在正文旁，不影响输入框或右侧文件面板，正文右侧预留窄槽。

鼠标进入刻度区展开用户输入列表，移动到列表内保持展开，离开后收起。键盘聚焦或点击刻度按钮也可展开，Escape 收起并将焦点还给刻度按钮。列表按消息顺序显示单行摘要，当前项高亮；点击条目只滚动对话区域到对应用户气泡，不改消息、折叠状态或输入草稿。Tab 可访问每一项，Enter/空格触发跳转；触屏可点击入口。长列表内部滚动，打开时使当前项可见。支持减少动画偏好。

超过 28 条时刻度均匀抽样，并始终保留当前输入的标记；展开列表保留全部已加载输入。无文本输入使用图片数量或附件文件名摘要，文本去除附件协议标签、压平空白并截短，不把原始图片数据放进列表。

列表使用紧凑布局：不显示“用户输入”、数量或关闭按钮所在的标题栏，直接显示输入摘要；宽度上限 280px，单行高度 28px，列表四周内边距 6px，滚动高度上限 300px，圆角 12px。收起继续使用鼠标离开、焦点离开、Escape 或选中条目，不额外占一行。

## 数据与滚动

- `lib/user-message-index.ts` 负责从 timeline 提取稳定 id 与摘要、刻度抽样和根据数值位置判定当前输入，保持无 DOM/IPC 副作用。
- `ConversationNavigator` 负责悬停、焦点、展开列表与跳转交互；独立滚动定位 hook 测量用户气泡，响应滚动、内容尺寸变化、缩放、历史前插与窗口变化。读取实际布局坐标以适配 CSS zoom，动画帧合并测量。
- `UserBubble` 根节点暴露消息 id，`TimelineItem` 传入原始 entry id；不增加布局包装层。
- `MessageList` 提供原有滚动容器和内容容器。跳转前关闭底部自动跟随，避免流式输出把用户拉回底部；用户回到最底部或点击“回到最新”时继续沿用原有规则。
- 列表有更早历史时显示“加载更早的输入”，复用原有分页入口与滚动高度补偿，不在悬停时扫描全部会话。加载失败沿用现有提示。列表只代表已加载消息，不承诺未加载页的全局编号。
- 前插历史期间临时关闭浏览器自带滚动锚定，由现有高度差补偿单独负责位置保持，补偿后恢复；避免浏览器与应用各补偿一次造成跳动。
- 切换会话时重建导航局部状态，避免旧会话的当前项和展开状态泄漏。

## 平台与验证

Windows/macOS 共用 React、浏览器滚动 API 和语义颜色变量，无原生接口、路径、文件系统或 sidecar 契约变化。三套皮肤共享结构；窄窗口仍可打开列表，列表宽度限制在对话区域内。

纯函数测试覆盖消息过滤、重复正文的独立 id、长文本、多行空白、图片/双平台附件、当前阅读轮次、底部和空列表、密集刻度保留当前项。组件验收使用真实 MessageList 与受控演示记录，检查刻度收起/悬停展开、点击跳转、滚动高亮、Escape、长列表、明暗与窄栏、缩放、分页、流式更新与切换会话，并保存截图。原生 IPC 不纳入组件测试。

## 验收结果

- `npm run check` 通过：桌面端类型检查、60 个测试文件共 774 项测试，其中新增 9 项导航纯逻辑测试。
- 实际 MessageList 组件配合演示记录：鼠标进入刻度区展开列表，离开收起；点击第四条输入后气泡距滚动区域顶部 16px，当前刻度同步高亮。追加流式正文后保持同一阅读位置。
- Escape 收起并聚焦刻度按钮；Enter 展开、Tab 进入列表控件。弹层避开刻度按钮的点击范围，防止悬停展开后误点消息。
- 加载更早历史前后同一气泡的屏幕位置差小于 1px；360px 内容栏与 160% 对话缩放下仍准确跳转，无横向溢出，弹层在对话区域内。
- 80 条输入显示 28 个刻度，列表保留全部 80 条并可内部滚动，打开时当前项可见。切换到单条输入的新会话后旧导航移除。
- 保存暗色收起、暗色悬停展开与纸间窄栏截图。浏览器验收无脚本错误或警告；使用演示数据与分页替身，未验证原生 WebView、真实历史 IPC 或 macOS 实机。
- 紧凑版复验：移除标题栏后，9 条输入的弹层宽 280px、高约 266px，单行 28px；点击条目仍收起列表并定位到气泡顶部 16px。已保存更新截图。本次仅修改展示，按 UI-only 例外不重复运行纯逻辑测试。
