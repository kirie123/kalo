# 对话区 SVG 渲染与内联 HTML 降级

## 背景

助手在回答里输出 SVG（内联 `<svg>…</svg>` 或 ```svg 代码块）时，对话区只会显示一坨 XML 源码：
`MarkdownBlock` 用的是 `react-markdown` 默认配置，没有 `rehype-raw`，原始 HTML 被当纯文本丢出来。
让模型能"画图"是很自然的需求（流程图、示意图、卡片），本次给对话区加上 SVG 渲染。

## 目标与非目标

目标：

- 内联 `<svg>…</svg>`（正文里直接写的）渲染成图形
- ```svg 围栏代码块渲染成图形
- 图形块带工具条：预览/源码切换、复制源码、另存为 `.svg`
- 流式输出中未闭合的 SVG 不闪源码，显示占位
- 白名单内的普通 HTML（`<h3>`、`<br>`、`<table>`…）不再以源码形式出现在正文里

非目标：

- **不开放任意 HTML**。不引入 `rehype-raw`；SVG 片段单独摘出渲染，其它白名单 HTML 走
  「降级成 markdown」而不是注入 HTML，白名单外的标签仍保持源码可见。
- 不改对话区的 HTML 渲染通道：`.html`/`.svg` 的文件预览渲染后来在
  [HTML 文件预览：沙箱渲染 + 本地资源内联](2026-09-17-html预览渲染.md) 里落定（沙箱 iframe，
  与对话区这条「不注入」的路径互相隔离）。
- 不做画布交互（缩放/拖拽/点击放大）。

## 方案

### 分层

```
src/lib/md-scan.ts           纯逻辑：代码感知扫描（围栏 + 行内代码）
src/lib/svg-render.ts        纯逻辑：分段 + 清洗 + id 命名空间 + 底色判定
src/lib/html-downgrade.ts    纯逻辑：白名单 HTML → markdown
src/lib/highlight.ts         纯逻辑：hljs 高亮 + 缓存（从组件层抽出，破除循环 import）
src/components/SvgBlock.tsx  展示：预览/源码切换、复制、另存为
src/components/AssistantMessage.tsx
  ├─ MarkdownBlock  先分段；markdown 段先过 htmlToMarkdown 再交 ReactMarkdown，svg 段走 SvgBlock
  └─ CodeRenderer   lang === "svg" → SvgBlock
```

`MarkdownBlock` 是共用入口（对话区、压缩摘要气泡、`.md` 文件预览都走它），所以这三处会一并获得 SVG 渲染能力。

### 分段（`splitSvgSegments`）

把一段 markdown 源码切成 `{ type: "markdown" }` 与 `{ type: "svg" }` 段：

- 扫描时跳过围栏代码块（``` / ~~~）与行内代码（`` ` ``）——`html` 代码块里贴的 SVG 源码必须保持是源码。
- 遇到 `<svg` 起始，按 `<svg`/`</svg>` 计数深度找到匹配的结束标签，整段切出。
- 到文本结尾仍未闭合（流式输出进行中）→ 该段标记 `complete: false`，组件渲染占位而不是半截源码。
- 未出现 SVG 时返回单个 markdown 段，渲染路径与现状完全一致。

代价：SVG 前后的 markdown 被切成两个 `ReactMarkdown` 实例，跨越 SVG 的 markdown 结构（例如列表项内部插 SVG）会断开。这是刻意取舍——模型输出的 SVG 几乎都在段落层级。

### 清洗（`sanitizeSvg`）

SVG 通过 `dangerouslySetInnerHTML` 注入，内容来自模型/工具输出，必须先清洗。纯正则实现（lib 层不碰 DOM，node 环境可测）：

- 删除 `<script>`、`<foreignObject>`（可嵌回任意 HTML）、`<!DOCTYPE>`/`<!ENTITY>`/`<?xml?>`、注释
- 删除所有 `on*` 事件属性
- `href` / `xlink:href` 只保留 `#片段` 与 `data:image/*`，其余（`http(s):`、`javascript:`、本地路径）整条属性删掉——顺带堵死外链追踪
- `style`/属性值里出现 `javascript:`、`@import` 的整体剔除
- 源码超过 `MAX_SVG_SOURCE`（256 KB）判为不可渲染，返回 `null`，组件降级成代码块
- 找不到 `<svg` 根标签也返回 `null`

另外做 **id 命名空间**：同一条消息里两张 SVG 都用 `id="g1"` 时，后一张的 `url(#g1)` 会引用到前一张的渐变。把 `id="x"` 改写成 `id="<prefix>-x"`，同时改写 `url(#x)`、`href="#x"`、`xlink:href="#x"`。prefix 由源码内容哈希得到，保证纯函数（同样输入同样输出，不依赖计数器/随机数），流式重渲染也不会跳。

### 展示（`SvgBlock`）

- 容器 `.svg-block`，工具条与 `.md-codeblock-bar` 同款：左侧 `SVG` 标签，右侧「源码/预览」切换 + 复制 + 另存为
- 预览区 CSS 约束：`svg { max-width: 100%; height: auto; }`
- 底色自适应（`hasOwnBackdrop`）：图自己铺满了背景（根元素声明 `background`，或有一块覆盖 ≥96% viewBox 且有实心 `fill` 的 `rect`）→ 画布透明贴卡片；否则补浅色底，防止深色主题下黑线画在黑底上看不见
- 清洗返回 `null` → 直接按代码块显示源码，并在工具条提示"无法渲染"
- 源码视图复用 `highlight(code, "xml")`，与其它代码块一致

### 另存为（新增 IPC）

导出需要写任意路径，现有命令里没有通用写文件。新增一条 Tauri 命令：

```
write_file_text { path, contents } -> void
```

- 实现在 `src-tauri/src/files.rs`，`main.rs` 注册，前端经 `pi-bridge.ts` 的 `writeFileText(path, contents)` 调用
- 行为：父目录不存在则创建；写 UTF-8；失败返回可操作错误（路径 + 原因）
- 路径由 `@tauri-apps/plugin-dialog` 的 `save()` 对话框产生，用户自己选位置；命令本身不做白名单
- 双平台：只用 `std::fs`，不拼平台相关分隔符，Windows / macOS 行为一致

### 白名单 HTML 降级（`htmlToMarkdown`）

模型偶尔直接吐 `<h3>`、`<br>`、`<table>`。这里**不渲染 HTML，而是改写成 markdown**，再交给 remark：
`<b>x</b>` → `**x**`、`<h3>x</h3>` → `### x`、`<br>` → 硬换行、`<ul><li>` → `- `、`<table>` → GFM 表格、
`<pre><code>` → 围栏块、`<a href>` / `<img src>` → markdown 链接/图片（URL 限 `http(s):`/`mailto:`/站内/`data:image`）。

- 全程零 `dangerouslySetInnerHTML`，攻击面与改动前完全一致
- `script`/`style`/`iframe`/`object`/`embed`/`template`/`noscript` 连内容一起丢弃
- `span`/`font`/`u`/`sub` 这类没有 markdown 对应物的包装标签只脱壳留字
- 列表与引用**由内向外**改写（`replaceInnermost`），否则惰性匹配会配错闭合标签，嵌套列表会散架
- 白名单外的标签（如 `<custom-thing>`）原样留着——宁可让用户看见源码，也不静默吞内容
- 全过程经 `mapOutsideCode`：围栏与行内代码里的标签绝不改写

为什么不用 `rehype-raw` + `rehype-sanitize`：那是把 HTML 真的渲染出来再做清洗，工具结果、抓取的网页正文都会进入同一条通道；
降级方案把「HTML 语义」和「HTML 执行」彻底解耦。附带好处是不加运行时依赖。

## 测试

`src/lib/svg-render.test.ts`（纯逻辑）：

- 分段：无 SVG 原样返回；围栏/行内代码里的 SVG 不被切；多张 SVG；嵌套 `<svg>`；未闭合标记 `complete: false`
- 清洗：`<script>` / `on*` / `javascript:` / `foreignObject` 被去掉；`href="#id"` 与 `data:image/png` 保留、`href="https://…"` 被删；超长返回 `null`；无根标签返回 `null`
- id 命名空间：`id` 与 `url(#id)` 同步改写；同输入同输出
- 底色判定：满幅 `rect`／根元素 `background` 判 true；小图形、`fill="none"`、纯描边图判 false

`src/lib/md-scan.test.ts`：围栏（``` / ~~~ / 缩进 / 未闭合）、行内代码（单双反引号、落单反引号）的边界。

代码区不被改写、白名单外标签保持源码。
